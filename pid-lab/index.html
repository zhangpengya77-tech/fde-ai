第一步：認識 PID、Rate 與濾波

P · I · D · FF

P（比例）：誤差越大、修正越大；太高會抖動與過衝，太低反應鬆軟。

I（積分）：消除長時間存在的偏差（例如重心偏移、風）；太高會慢速擺盪。

D（微分）：抑制變化速度，提供阻尼、減少過衝；但會放大高頻雜訊，使馬達發熱。

FF（前饋）：直接依搖桿變化給出力量，讓響應更跟手，不依賴誤差。

Rate 與控制迴路

Rate（目標角速度）：搖桿打到某位置時，飛控希望機體轉多快（deg/s）。

角速度內環：比較目標角速度與陀螺儀實際角速度，是 PID 調參的主要對象。

姿態外環（ArduPilot / PX4 自穩模式）：比較目標角度與實際角度，輸出內環的目標角速度。

濾波基礎

陀螺儀會收到馬達與螺旋槳的振動。低通濾波去除高頻雜訊、陷波 / 動態陷波 / RPM 濾波精準去除特定頻率。

濾波越強，延遲越大，控制越不穩；所以要先把機械振動處理好，再談濾波。

怎麼讀曲線

時間曲線：目標（虛線）與實際（實線）越貼近越好。

階躍響應：理想為快速上升到 1、過衝小、很快穩定。

頻譜：橫軸頻率、縱軸雜訊強度；尖峰代表特定振動來源。

飛行前準備：讓日誌可以被分析

日誌記錄頻率太低時，系統只能顯示「資料不足」。下列設定在官方地面站中由學員手動完成（本系統不會寫入參數）；修改前先備份參數，連接飛控時拆下螺旋槳。參數名稱與選項可能隨韌體版本不同，請以該版本官方文件為準。

ArduPilot（Mission Planner）

目的：角速度內環需 ≥ 50 Hz；濾波分析需要 IMU 批次取樣。

  1. 完整參數表搜尋 LOG_BITMASK，在勾選清單中加入 ATTITUDE_FAST 與 PID（保留原本已勾選的項目）。
  2. INS_LOG_BAT_MASK = 1（記錄第一顆 IMU 的批次取樣）。
  3. INS_LOG_BAT_OPT = 4（同時記錄濾波前與濾波後，可比較濾波效果）。
  4. 寫入參數後重新開機飛控。

檢查方法：上傳日誌後，「5 PID / 濾波」頁應出現「濾波前 / 濾波後（批次取樣）」頻譜；若角速度仍顯示 10 Hz，請教師確認該韌體版本的記錄選項。批次取樣會增加日誌大小，飛完驗證後可恢復原設定。

Betaflight（Configurator）

目的：Blackbox 記錄率足夠高，才能看見 PID 響應與 100 Hz 以上的雜訊。

  1. 「Blackbox」頁：記錄裝置選 Onboard Flash 或 SD 卡，飛行前先清除（Erase）Flash。
  2. 記錄頻率（Blackbox logging rate）至少 1 kHz，2 kHz 更佳（依飛控記憶體容量調整）。
  3. CLI 執行 version 與 diff all，把輸出存檔後在實驗室「參數 / CLI 匯入」貼上。

檢查方法：上傳後「5 PID / 濾波」頁的取樣頻率應 ≥ 1000 Hz，並出現階躍響應曲線。

PX4（QGroundControl）

目的：角速度與目標角速度需要高頻記錄。

  1. 參數 SDLOG_PROFILE：在勾選清單中加入 High rate（需要系統辨識時再加 System identification），保留預設項目。
  2. SDLOG_MODE：建議「從解鎖到上鎖」記錄。
  3. QGroundControl「參數 → 工具 → 儲存到檔案」匯出參數，在實驗室匯入。

檢查方法：上傳 ULog 後，角速度取樣頻率應明顯高於 100 Hz。

建議的測試飛行動作（三套飛控通用）

  1. 確認螺旋槳、電池電量與安裝牢固；教師在場、場地淨空。
  2. 低空懸停 30 秒（供振動與雜訊分析）。
  3. 橫滾軸：快速左右打桿再回中，重複 3～5 次；俯仰軸、偏航軸同樣各 3～5 次（供階躍響應分析）。
  4. 再懸停 10 秒後降落，記錄電池編號、螺旋槳與風況。
  5. 調參前（BASELINE）與調參後（AFTER_TUNING）使用相同的動作、電池與螺旋槳，前後比較才有意義。
