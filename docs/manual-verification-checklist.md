## 2. 人工判定清單

### A. 開場與可見性

- [ ] **A1** 進入 `?mode=exam` 後，**一眼就能看到停在地面的無人機**（在 H 起降圈內，不是一個小點）。
      *自動量測：投影 640,350、尺寸約 50px @1280×720。*
- [ ] **A2** 機體外形可辨識為四軸（四臂、四槳、機頭有黃色方向錐、下方兩支起落架），不是方塊。
- [ ] **A3** 頂欄顯示科目列（A/B/C/D/F/G）、步驟條、風況摘要；右側窄欄是即時面板（小地圖、模式、風、輸入來源、免責）。
- [ ] **A4** 底部中央有三顆按鈕：`起飛 (T)`／`懸停`／`降落 (L)`；未選科目時「起飛」是灰的、滑過去看得到原因。

### B. 起飛流程（最關鍵）

- [ ] **B1** 未選科目時按 `T`：下方提示變成「**請先選科目（點上方科目按鈕）**」，**不是靜默無反應**。
- [ ] **B2** 點科目 B 後：步驟條 ② 高亮、狀態「未起飛」、起飛鈕變亮可按。
- [ ] **B3** 按 `T`（或點起飛鈕）：機體**明顯離地上升**，最終穩定在 1.5 m；狀態依序「起飛中 → 飛行中」。
- [ ] **B4** 離地後槳葉轉速變快（視覺可辨），地面時較慢。
- [ ] **B5** 起飛後**放開所有按鍵**，機體原地不動（無風時水平位移量測 0.000 m），不會自己飄走或往下掉。
      *這是最容易被誤判為「壞掉」的一項：實體搖桿油門停在最底部時，系統會鎖住該值當定高基準。*
- [ ] **B6** 按 `L` 降落：狀態「降落中 → 已降落」，高度回 0，**可以再按 T 重新起飛**（不需重新整理）。

### C. 風況（本輪新增）

- [ ] **C1** 頂欄右側「風況摘要」預設顯示 `風：無風｜平均 0.0 · 陣峰 0.0 m/s（即時 0.0）`。
- [ ] **C2** 點摘要展開面板：有「風況」下拉，四個選項，且「微風」「接近門檻」選項文字標著「**非官方**」。
- [ ] **C3** **展開面板時，科目列與步驟條不得跳動**（面板是浮層）。
- [ ] **C4** 選「微風」→ 顯示 `平均 2.0 · 陣峰 4.0`，即時值在 2.0–4.0 之間跳動，**不超過 4.0**，無 ⚠。
- [ ] **C5** 選「接近門檻 7/9」→ 顯示 7.0／9.0，**不出現 ⚠**（差一點未達 7.5／10）。
- [ ] **C6** 選「觸發宣告 7.5/10」→ 出現橙色 `⚠ 需安全宣告`，面板內顯示安全宣告原文。
- [ ] **C7** 切回「無風」→ ⚠ 消失，即時值歸 0。
- [ ] **C8** 在「微風」下起飛，機體會被風帶動、需要頂風修正（這是預期行為，不是故障）。

### D. 視角與版面

- [ ] **D1** 按 `V` 依序切換：考生視角 → 追隨 → 俯視全景 → 回到考生視角（右側面板「視角」同步）。
      *三種視角的機體實測尺寸：考生 50 px、追隨 36 px、全景 14 px（1280×720）。全景同時要看到八字符與起降點，機體必然比考生視角小；若你認為仍太小，`simAssist.camera.views.overview` 可再調。*
- [ ] **D2** 預設是**考生視角**（站在 H 後方約 7 m、眼高 1.6 m），不是遠到看不清機體的空拍視角。
- [ ] **D3** 1280×720 下各面板**互不重疊**，場景中央沒有被面板蓋住（自動量測 4 面板、中央 40%×50% 淨空）。
- [ ] **D4** 1366×768、1920×1080 各看一次，版面不得擠壓或出現橫向捲軸。

### E. 科目實作（各跑一次完整流程）

每科都是獨立一次飛行：**點科目 → 起飛 → 飛完動作 → 降落 → 看判定**。

- [ ] **E1 科目 B 定點起降四面停懸**：起飛後在原點依序朝四個方向各停 5 秒以上，降落。
      預期：判定 **S**；無風下五面停懸秒數約 6–7 s。
- [ ] **E2 科目 C 8 字水平圓**：沿雙圓飛完一圈（左圈、右圈各一次），不得停頓。
      預期：判定 **S**；軌跡偏差 0.000 m、最長停頓 0.00 s。
- [ ] **E3 科目 D 側面停懸及前進後退**：六個定點各停 5 秒、再前進後退共 12 m。
      預期：**無風下 S**；**微風下會是 U**（見第 3 節已知落差，不是操作錯誤）。
- [ ] **E4 科目 F 緊急處置**：飛行中按 `E` 由監評下達緊急返航，口誦後原處懸停、飛回較近一側八字內圈降落。
      預期：判定 **S**；觸發時間約 9.1 s、位置約 (8.0, −8.4)。

### F. 成績單

- [ ] **F1** 降落後按 `Enter`（或點「產生成績單」）：成績單**完全不透明**，下方即時面板不會透出來形成鬼影。
- [ ] **F2** 成績單含：附錄 5 七項 S/U/N、重大違失表、模擬判定（S/U）與官方合格標準、重新測驗／重播按鈕。
- [ ] **F3** 按 `Esc` 可返回場景並重新開始。

## 3. 已知落差（不阻擋驗收，但請知情）

| 項目 | 現象 | 量化 | 目前處置 |
|---|---|---|---|
| 科目 D × 微風 | 理想操作拿不到 S（`subjectD.hoverFail`） | 六個定點需各停 ≥4.8 s，微風下實測 2.80／4.35／4.80／2.40／2.15／4.77 s，**2/6 達標**，缺口 0.45–2.65 s（合計 7.53 s）；其餘全部達標（漂移 0.074–0.234 m ＜0.5、後退 12.40 m ≥12、等高 1.50 m） | **未放寬任何閾值**。根因是「有風必須持續頂風」造成 0–0.35 m/s 的對地速度極限環，越過 0.3 m/s 的靜止門檻。待教師決定是否改飛控語意（放桿即空速歸零）或拉長陣風週期 |

**這不是**「微風太強」：微風 2/4 是模擬假設（非官方），無風是預設值。若要示範 D 的合格操作，請用預設無風。

## 6. 回報格式

逐項回報即可，例如：

```
A1 PASS  A2 PASS  A3 PASS  A4 PASS
B1 PASS  B2 PASS  B3 PASS  B4 PASS  B5 PASS  B6 PASS
C1 PASS  C2 FAIL（展開後下拉選單被右側面板遮住）  ...
```

有 FAIL 請附：**哪一項、當下解析度、截圖或螢幕錄影**。
若畫面「能用但難用」，請直接描述觀感（機體太小／字太小／顏色看不清），這類意見不會被自動測試捕捉。
