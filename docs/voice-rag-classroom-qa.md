# FDE-AI 本機 RAG 助教課堂測試題

本文件整理 FDE-AI 1.1 MVP 的本機教材查詢型 AI 助教測試題。回答標準以 `E:\FDE_AI_Voice_RAG\knowledge_base` 教材為準，不連接 OpenAI API。

## 1. F450 裝機前要先檢查什麼？

標準答案：先確認零件齊全，包括 F450 機架、機臂、馬達、ESC、Pixhawk 2.4.8、GPS / 指南針、接收機、電源模組、電池與 CW / CCW 槳葉。組裝前要確認正負極、線材、接頭、螺絲與機頭方向。涉及通電或馬達測試前，必須拆下槳葉並請老師確認。

## 2. CW 和 CCW 是什麼？

標準答案：CW 是順時針方向，CCW 是逆時針方向。F450 四軸需要兩片 CW 槳與兩片 CCW 槳交錯安裝。檢查時不能只看槳葉文字，還要確認馬達位置、馬達旋轉方向與槳葉前緣方向。

## 3. 槳葉裝反會怎樣？

標準答案：槳葉裝反會讓升力方向或扭力配置錯誤，可能造成無法穩定起飛、起飛翻機或失控。處理時不要直接再試飛，應先拆下槳葉，重新確認 CW / CCW、馬達方向、馬達序號與飛控方向，最後請老師複核。

## 4. Pixhawk 怎麼接線？

標準答案：Pixhawk 2.4.8 的箭頭要朝機頭。電源模組接 POWER，GPS / 指南針接 GPS / I2C 相關端口，接收機接 RC IN，四個電調訊號線接 MAIN OUT 1 到 MAIN OUT 4，USB 可接電腦做 Mission Planner 設定。接線不確定時不要通電或解鎖。

## 5. 電池充電要注意什麼？

標準答案：先檢查電池是否膨脹、破損、發熱、漏液或接頭燒黑。充電時要選對電池類型、電芯數、通道與充電電流，主電源頭和平衡頭都要接好。充電時不要離開現場，電池要放在安全位置，遠離易燃物。

## 6. Mission Planner 要先做哪些校正？

標準答案：先確認 Pixhawk 固定方向、USB 或數傳連線、電池與電源模組、GPS / 指南針方向都正確。基本設定順序是機架類型、加速度計校正、指南針校正、遙控器校正、飛行模式、FailSafe，然後做無槳馬達測試。

## 7. 飛機起飛會翻通常是什麼原因？

標準答案：常見原因包括 CW / CCW 槳葉裝反、馬達轉向錯誤、馬達序號接錯、飛控方向設定錯誤或機架類型設定錯誤。處理方式是立刻停止試飛，拆下槳葉，回到馬達測試與方向檢查流程。

## 8. 通電前檢查清單有哪些？

標準答案：通電前要確認所有槳葉已拆下或確認不是馬達測試階段，正負極沒有接反，電源模組與 Pixhawk POWER 接線正確，ESC、馬達線與機臂固定沒有鬆動，接收機與 GPS / 指南針接線正常，機體沒有短路、異味、冒煙或發熱跡象。

## 9. 為什麼不能先裝槳測試？

標準答案：裝槳後馬達一旦誤轉，槳葉會產生切割與撞擊風險，也可能因馬達方向、序號或飛控設定錯誤導致翻機。第一次通電、校正與馬達轉向測試都必須拆下所有槳葉，確認無誤後才由老師安排下一步。

## 10. AI 檢測結果怎麼判斷？

標準答案：AI 檢測只是初步提示。PASS 表示主要項目看起來正常，但仍需老師確認；WARNING 表示可能有風險或信心度不足，應補拍清楚照片並請老師複核；FAIL 表示缺少必要零件或存在高風險，不可通電、解鎖或實飛。判讀 F450 照片時要看馬達、機臂、CW / CCW 槳葉、飛控方向、GPS / 指南針、電池固定與線材狀態。
