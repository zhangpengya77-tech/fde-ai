## 1. 實際完成

| 功能 | 說明 | 位置 |
|---|---|---|
| 參數備份上傳 | 讀完參數後按「上傳目前參數備份」。伺服器驗證每一行格式（參數名稱、數值），去掉註解後存成標準格式，並記錄 SHA-256；大小上限 200 KB、最多 3000 個參數 | `results_api.py` |
| 差異報告 | 和同一學員、同一台飛控的上一份備份比對，列出變更、新增、移除 | `results_api.py` |
| 教師覆核 PASS／NG | 參數備份和已完成的寫入都可以覆核，可加備註；教師只能覆核自己班級的紀錄，不能覆核自己的紀錄 | `results_api.py` |
| 任務卡 | 三個步驟：上傳備份 → 完成一次批准的調參寫入 → 取得教師 PASS。**完成狀態全部由伺服器紀錄判斷**，不由瀏覽器自行宣稱 | `results_api.py`、`gcs.js` |
| 班級成果 CSV 匯出 | 教師選班級匯出；只含學員編號，不含 email 和姓名；儲存格開頭的 `= + - @` 會被跳脫，避免 Excel 公式注入 | `results_api.py` |
| AI 調參助教 | 點參數名稱顯示**教師撰寫的固定說明**（用途、調高、調低、注意事項）和白名單範圍；「問 AI 助教」使用網站既有的同源 RAG 端點 `/api/public/rag/ask/`。這個區塊**沒有任何套用或寫入按鈕** | `param_explanations.json`、`gcs.js` |
| 學員／教師 SOP | 學員五步驟手冊、教師開放、批准、覆核、匯出手冊 | `FDE_GCS_STUDENT_SOP.md`、`FDE_GCS_TEACHER_SOP.md` |

新增 migration：`gcs_portal/migrations/0002_*`（寫入申請表加上覆核欄位，新增參數備份表 `ParamBackup`）。
