# FDE-AI 地面站（FDE-GCS）學員操作手冊

> 適用：FDE-GCS Web 1.0，Windows 電腦的 Chrome 或 Edge。手機不能使用。

## 上課前的安全規則（一定要遵守）

1. **調參練習時，螺旋槳一律拆下，動力電池一律斷開**，只用 USB 供電。
2. 打開 FDE-GCS 前，**先關閉 Mission Planner、QGC** 等其他地面站。同一個 USB 連線，同一時間只能給一個程式使用。
3. FDE-GCS 沒有解鎖、起飛、切換模式的按鈕，這是刻意的設計。

## 步驟一：連線飛控

1. 登入學習平台，按右上角的 **「FDE-AI 地面站」**。看不到這個入口，代表你的班級還沒開放，請問教師。
2. 連線模式選 **「真機（USB）」**。
3. 按 **「選擇 USB 並連線」**，在跳出的視窗中選你的飛控（通常名稱有 `COM` 和 `ArduPilot` 或 `STM`），再按「連線」。
4. 「Heartbeat」顯示綠色 **「正常」**，就代表連上了。飛控儀表板會開始出現數值。

**常見問題**
| 畫面訊息 | 處理方式 |
|---|---|
| 「這個 USB 連線正被其他程式使用」 | 關閉 Mission Planner 或 QGC，再按一次連線 |
| 一直顯示「等待飛控心跳」 | 檢查 USB 線、確認 Baud Rate 是 115200，按「中斷」後重新連線 |
| 「訊號中斷」或「已斷線」 | USB 可能鬆了；重新插好後按「中斷」再連線 |

## 步驟二：讀取參數並上傳備份（任務卡第 1 項）

1. 按 **「讀取全部參數」**，等到顯示「完成：共 N 個參數」。
2. 按 **「上傳目前參數備份」**。上傳後，下方「參數備份」會出現一筆紀錄。
3. 也可以按「匯出備份」，把 `.param` 檔存到自己的電腦。

## 步驟三：認識參數（AI 調參助教）

1. 在參數表的搜尋框輸入名稱，例如 `ATC_RAT_RLL`。
2. **點參數名稱**，右邊「AI 調參助教」會顯示教師寫的說明：用途、調高和調低的效果、注意事項，以及允許的範圍。
3. 想知道更多，可以按 **「問 AI 助教」**。AI 的回答只是參考，**不會改動飛控**。

## 步驟四：申請調參並寫入（任務卡第 2 項）

1. 只有白名單內的 PID 參數（`ATC_RAT_*`）旁邊會出現 **「申請修改」**。
2. 輸入新值。每次修改幅度**不能超過 30%**，而且要在允許範圍內，不符合時「送出申請」按不下去。
3. 勾選 **「我確認已拆下螺旋槳、已斷開動力電池」**，再按 **「送出申請給教師」**。
4. 等教師批准。批准後，申請旁邊會出現 **「寫入飛控…」**，**10 分鐘內有效，只能用一次**。
5. 按「寫入飛控…」，畫面會列出寫入前檢查，**每一項都要打勾**；再勾一次安全確認，按 **「確認寫入飛控」**，確認視窗會顯示原值和新值。
6. 看到 **「寫入成功，讀回值一致」** 就完成了。參數表裡改過的參數會變成黃色。

**寫入前檢查沒過時**
| 未通過的項目 | 原因 |
|---|---|
| 飛控已上鎖 | 飛控被解鎖了。拆槳狀態下也不能在解鎖時寫入，請先上鎖 |
| 教師已批准 | 可能超過 10 分鐘、換了另一台飛控，或參數已經被改過。請重新申請 |

## 步驟五：再備份一次，查看差異，等教師覆核（任務卡第 3 項）

1. 按「再讀一次並比對」，再按「上傳目前參數備份」。
2. 在新的備份上按 **「差異報告」**，會列出和上一份備份相比，改了哪些參數。
3. 教師覆核後，紀錄會顯示 **PASS** 或 **NG**。任務卡三項都打勾，就完成這個單元了。
