# FDE-AI 地面站（FDE-GCS）教師操作手冊

> 適用：FDE-GCS Web 1.0。

## 一、開放功能（管理者設定）

| 設定 | 說明 |
|---|---|
| `FDE_GCS_ENABLED=1` | 開啟 FDE-GCS。設成 `0` 或刪除這個變數，入口和所有 API 立即消失（一鍵關閉） |
| `FDE_GCS_COHORTS=2026-06` | 開放的班級（逗號分隔）。只有這些班級的學員看得到入口 |
| 教師班級指派 | 沿用學習平台既有的「教師班級存取權」（`TeacherCohortAccess`）。教師只看得到被指派且已開放的班級 |

## 二、上課前檢查

1. **白名單**：確認 `student_portal/gcs_portal/param_allowlist/arducopter-4.json` 的上下限適合你的機體，確認後把 `approved_by` 改成你的姓名。
2. **參數說明**：確認 `student_portal/gcs_portal/param_explanations.json` 的文字，確認後把 `status` 改成 `APPROVED`。
3. **全班拆槳**：寫入參數的課程，所有飛控一律拆槳、只用 USB 供電。
4. 請學員關閉 Mission Planner、QGC。

## 三、批准寫入申請

1. 打開「FDE-AI 地面站」，在「寫入申請紀錄」可以看到你班級學員的申請：參數、原值 → 新值、學員編號、班級。
2. 檢查新值是否合理（系統已經擋掉超出範圍和超過 30% 的修改）。
3. 按 **「批准」** 或 **「退回」**。批准後學員有 **10 分鐘**可以寫入，而且只能寫一次；過期就要重新申請。
4. 學員寫入後，紀錄會變成「已寫入並讀回確認」或「寫入失敗」。

**建議**：批准前請走到學員旁邊，親眼確認螺旋槳已拆下。

## 四、覆核學員成果（PASS／NG）

| 項目 | 在哪裡 | 覆核重點 |
|---|---|---|
| 參數寫入 | 「寫入申請紀錄」裡已完成的寫入 | 修改是否合理、是否讀回成功 |
| 參數備份 | 「學員成果 → 參數備份」 | 按「差異報告」看學員改了什麼 |

按 **PASS** 或 **NG** 後可以輸入備註，學員會看到。你不能覆核自己的紀錄。

## 五、匯出班級成果

在「學員成果」選擇班級，按 **「匯出班級成果 CSV」**。檔案包含：學員編號（不含 email、姓名）、參數備份、參數寫入、讀回值、覆核結果。

## 六、注意事項

1. **寫入是在學員電腦上執行的**：伺服器管控誰、何時、哪一筆可以寫，並保存完整紀錄；但無法阻止會改瀏覽器程式的人直接送封包。上課時請靠在場監督和拆槳規定把關。
2. 寫入不理想時，請學員再申請一次，把數值改回原值。
3. 任何異常（解鎖狀態、馬達轉動、冒煙）立即拔掉 USB。
