## 1. 一鍵還原

學員對「已寫入並讀回確認」的申請按 **「申請還原」**，系統會建立一筆標示「【還原】」的新申請，把參數改回當初的原值。

| 規則 | 說明 |
|---|---|
| 還原內容由伺服器決定 | 參數名稱、飛控 System ID、新值一律取自原申請；瀏覽器送來的值不採用（測試中刻意送 `ARMING_CHECK`／999，伺服器仍建立正確的還原申請） |
| 只限自己已寫入成功的申請 | 別人的申請、尚未寫入的申請都不能還原 |
| 飛控目前值必須仍是當初寫入的值 | 已經被改過就不能還原，請改用一般申請 |
| 每筆寫入同時只能有一筆還原申請 | 重複送出回 409 |
| **不套用 30% 幅度限制，但仍檢查白名單與範圍** | 原因：幅度以「目前值」為基準。例如 0.135 調低到 0.1（−26%），改回 0.135 以 0.1 為基準算是 +35%，一般申請會被擋。還原只能回到原值，所以放寬這一項 |
| 其他規則完全相同 | 仍需教師批准、10 分鐘有效、單次使用、6 道寫入檢查、讀回比對 |

新增 migration：`gcs_portal/migrations/0003_paramwriterequest_revert_of.py`（寫入申請表加上 `revert_of` 欄位）。

## 2. 教師待批准提醒

有待批准的申請時：
- 瀏覽器分頁標題前面顯示待批准筆數，例如 **(1) FDE-AI 地面站**
- 「寫入申請紀錄」標題改成 **「寫入申請紀錄（待你批准 1 筆）」**，並以黃色標示

清單每 5 秒自動更新，批准後提醒自動消失。
