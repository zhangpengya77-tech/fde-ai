## 3. 接線模式（自行設計）

- 切到俯視全螢幕 2D 視圖（右下保留可收合的 3D 小預覽）。
- 每一步：編號熱點（圓圈＋數字）標出焊點／接頭 → 白話說明（例：「電池負極接電源模組負極」）→ 學員點兩端或拖線 → 立即校驗（規則引擎）→ 進度 n／N。
- 圖例：線色（紅＝正極、黑＝負極、黃／白＝訊號）、極性符號、介面類型標籤（PWM／SBUS／UART／I2C）。
- 接頭對插：彈出放大示意，拖曳插入，檢查方向與針腳數。
- 完成：檢查結果頁（錯誤清單、可回到出錯步驟）。

## 4. 完成畫面

完成提示、零件清單（已裝／未裝）、錯誤統計（次數、類型）、用時、匯出紀錄按鈕；固定標示「模擬結果不能取代實際檢查」。

## 5. 手機

零件庫與步驟清單收成左右抽屜；底部操作列改成可橫向捲動；MVP 只保證檢視、旋轉、縮放與步驟前進。
