## 1. 做了什麼

**2D 接線區新增切換「接頭級（基礎）／引腳級（進階：一根一根接）」**。原本的接頭級完全保留。

引腳級畫布：
- **Pixhawk 2.4.8**：依 PX4 開源硬體 FMUv2.4.6 電路板座標等比例繪製（8 px／mm）。
  - 各接頭在板上的實際位置照原比例；引腳間距略為放大，方便點選。
  - 後端伺服排針照 2.54 mm 間距畫滿 16 欄 × 3 列（S／＋／−）。左起 RC、SB、MAIN 8→1、AUX 6→1。
  - 這台不用的接頭（TELEM、USB、SPI、CAN、ADC、SPKT、SERIAL4/5）畫成灰色、不能點。
  - 頁面標示「© PX4／3D Robotics，CC-BY-SA 3.0；本圖同授權」。
- **R9DS**：依官方尺寸 43×24×15 mm，CH1–CH9 排針，CH9 標 SBUS。
- **其他零件**：GPS（6P 串列＋4P 羅盤）、電調（電源＋／−、三相 A／B／C、訊號 S／＋／−）、馬達、配電板焊盤、電源模組（XT60＋6P）、電池、安全開關、蜂鳴器。
- **接線方式**：點一根引腳、再點另一根就接上。線依種類上色：5V／＋ 紅、GND 白、TX 藍、RX 綠、SCL 紫、SDA 青、訊號黃、三相灰。
- **正確接線共 54 根**，另有選配的數傳（不計）。

## 2. 引腳級檢查（`training/pins.js`）

| 錯誤 | 例子 | 扣分（試行） |
|---|---|---|
| 短路 | 5V 接 GND、＋接− | 安全 −5 |
| TX／RX 沒交叉 | GPS TX 接飛控 TX | 電源與訊號 −2 |
| 接錯腳 | 右前電調訊號接到 MAIN OUT 2 | 電源與訊號 −2 |
| 接到不用的腳 | GPS 的 CAN2 腳 | 電源與訊號 −1 |
| 電調紅線接到排針 | ESC 訊號線＋接 MAIN OUT＋ | 安全 −2 |
| 一腳多線、重複 | | −1 |
| 缺線 | 只接訊號沒接地線 | 該條連線不算完成 |

規則重點：
- **三相線**：任意順序都算對（交換兩根＝轉向相反，不是接錯）。
- **電調訊號線**：只接 S 和 −，紅線（＋）不接（Pixhawk 不供電給排針）。
- **換算回接頭級**：一條連線的引腳全部接對，才算一條接頭級連線。換算結果送給成績單、3D「顯示我的接線」線束、保存紀錄，原流程不用改。

## 3. 教學／練習／考核

- **教學**：點一根引腳，會閃爍標出正確的另一端，例如 GPS TX → Pixhawk GPS 第 3 腳（RX）。每次接線都自動檢查。
- **練習**：可以按「檢查引腳接線」和「完整引腳示範」（54 根依序畫出）。
- **考核**：從空白開始，不能檢查、不能示範；交卷後鎖定。
- 引腳級草稿另外存（`f450twin-wirepin-v1`），和接頭級草稿互不影響；考核不存草稿。

## 5. 測試

- 單元：引腳規則 13／13。
- 瀏覽器：引腳級 16／16，涵蓋：
  - 切換層級；
  - 標示授權；
  - 抓到 TX 沒交叉與短路；
  - 教學提示；
  - 54 根全接對後成績單計分（0 → 51）；
  - 重新整理後草稿保留；
  - 考核清空與禁止檢查、示範；
  - 回到練習還原；
  - 切回接頭級改用接頭級接線；
  - 沒有腳本錯誤。
- 回歸：見提交紀錄。

## 6. 仍待老師用實機核對

1. **GPS 模組端**：哪根線是 TX、RX，依品牌不同。目前用通用 M8N 接法。
2. **電調是否有 BEC**：目前當光耦、沒有 BEC。
3. **接頭類型**：DF13 或 Molex PicoBlade。
4. **R9DS**：實機確認用 SBUS 模式、CH9 口。

規則全部仍標「待實機核對」，分數為試行分數。
