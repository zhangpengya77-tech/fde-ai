## 5. 部署前需要你決定

1. **時間**：選沒有學員上課的時段（Django 重新啟動約 30 秒）。
2. **通知老師**：所有學員的任務完成度分母會從 12 變 13；已完成 12 張的學員會顯示 12／13。
3. **iPhone 實機**：建議部署後用 iPhone 走一遍（第 6 節）。如果想先實機測再上線，需要先放一個測試環境，目前沒有。
4. **GitHub 備份（可選）**：要不要把部署分支推到 GitHub 當異地備份。推送需要你另外同意。

## 6. 部署後人工檢查（約 10 分鐘）

用公開網址，電腦一次、iPhone 一次：

- [ ] 打開 `/f450-twin/`：上方原有五種模式正常，下方出現「無人機組裝與接線實訓」
- [ ] 按「開始 3D 組裝練習」，拖一件「下中心板」到綠圈，會吸附
- [ ] 按「開始 2D 接線練習」，連一條「電池 XT60 → 電源模組」
- [ ] 用**測試學員帳號**登入後，按「保存這次成績到練習紀錄」→ 出現「已存入」
- [ ] 學員「模擬練飛紀錄」頁看得到這筆（標試行分數）
- [ ] 教師「全班模擬練飛紀錄」頁看得到（分項＋試行最佳）
- [ ] 學員任務列表 M05 後面出現 **M13 FPV 穿越機接線實訓**，可以上傳 PNG
- [ ] 抽查其他功能：首頁、登入、空域查詢、模擬器正常

## 7. 回滾（腳本 `p8_rollback.ps1 -Tag backup/pre-f450-training-<日期>`，約 2 分鐘）

1. T13 設成停用：不刪除，保留可能已上傳的佐證。
2. 資料庫退回 0032：no-op，資料不變；已存的 F450 練習紀錄留在表中，舊版頁面顯示為原始類別值。
3. 程式退回部署前標籤：F450 頁立即恢復。
4. 重新啟動 Django（UAC）。

**不需要**還原整個資料庫。部署前備份只在資料損壞時使用，而且會失去部署後的所有新資料，要另外確認。

什麼時候回滾：
- 第 5 步自動檢查沒通過，且不能馬上修。
- 部署後原有功能出錯。
- 學員回報 F450 頁面無法使用。
