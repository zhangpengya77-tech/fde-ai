## 1. 做了什麼

### 2D → 3D
- 在 2D 畫布點一條線：3D 兩端零件發光，並畫出這條線，有 3 個光點沿線流動。
- 點一個接口或元件框：3D 對應零件發光。
- 3D 畫面上方出現說明條，寫出 2D 選了什麼，並附「到 2D 接線畫布 ↓」按鈕。
- 3D 模型沒有的零件（安全開關、蜂鳴器）會明白寫「3D 模型沒有：安全開關」，不假裝有。
- 在 3D 組裝練習中，還沒裝上的零件會寫「3D 目前看不到：ESC 右前（尚未組裝）」。
- 2D 取消選取時，3D 的高亮和說明一起清除。
- 2D 沒選東西時，不會清掉 3D 自己的高亮（例如接線圖表格選的線）。

### 3D → 2D
- 在 3D 點零件，或從左側零件清單、引線標籤選零件：2D 畫布用黃框標出對應元件，狀態列寫「3D 選取：…」。
- 從清單選「電子變速器」會框出四顆 ESC；在 3D 直接點某一顆，只框那一顆。

### 在 3D 顯示我的接線
- 2D 面板新增「在 3D 顯示我的接線」勾選：把學員自己接的線畫在 3D 上。
- 按過「檢查接線」後：綠＝對、紅＝錯；沒檢查前依類型上色（電源紅、訊號藍、資料綠）。
- 線會跟著爆炸動畫、組裝練習的零件移動。
- 另有「到 3D 畫面看 ↑」按鈕（2D 在頁面下方、3D 在上方）。

## 3. 修正 P2 的一個問題（P4 開發中發現）

**3D 組裝練習裡看不到 Pixhawk 飛控本體，只看得到減震泡棉。**

- 原因：three.js 載入模型時，除了把空白換成底線，還會刪掉名稱裡的「.」，所以「Pixhawk 2.4.8」變成「Pixhawk_248」。P2 只處理了底線，這個節點對不上任何組裝單元，在練習模式中一直隱藏。
- 為什麼 P2 沒抓到：當時驗收只檢查「每件至少一個節點看得到」；Pixhawk 單元的泡棉看得到，所以通過了。
- 修正：
  - 比對時兩邊都去掉空白、底線、`.`、`:`、`/`、`[`、`]`。
  - 單元測試改用 three.js 實際的改名規則。
  - P2 驗收加「組完後 59 個節點全部看得到」，現在 59／59。
