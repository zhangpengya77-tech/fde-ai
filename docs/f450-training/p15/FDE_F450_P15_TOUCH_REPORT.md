# F450 實訓 P15 報告：手機觸控拖曳

- 日期：2026-11-15
- 依據：使用者回饋（手機截圖）。手機版很難用，要能像電腦一樣從零件欄拖進工作區，並用觸控拖曳接線。

## 改了什麼

1. **零件欄改用指標事件拖曳**：滑鼠、手指共用同一套操作。拖曳時零件圖跟著手指移動，零件欄變淡，放開的位置就是零件位置。點一下卡片也能加入。
2. **按住引腳拖到另一根引腳放開就接線**：會自動吸附到最近的引腳，觸控 30 px、滑鼠 16 px 內都算；目標引腳亮黃色。原本「點兩根引腳」接線的方式保留。按下時會找手指附近的引腳（觸控 24 px、滑鼠 9 px），縮小畫面時引腳很密也點得中。
3. **精簡版版面**：手機直式（寬 ≤ 760）或手機橫式（高 ≤ 560 且觸控）時切換。
   - 零件欄改成工具列下方的橫向滑動卡片列，往下拖就能拖進工作區；
   - 縮放列改到右側直排，避開手機瀏覽器底部的按鈕；
   - 狀態列接在零件欄下方，點一下可展開上電報告；
   - 工具列縮成一列（「完整接線示例」縮成「示例」）；
   - 橫式時頁首、零件欄、狀態列再壓扁；
   - 頁面高度改用 100dvh。
4. **修正錯誤**：手機上「＋ 配件」收起後，零件欄仍然顯示（CSS 覆蓋了 hidden）。
