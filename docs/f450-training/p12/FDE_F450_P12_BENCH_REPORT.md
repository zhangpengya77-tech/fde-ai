# F450 實訓 P12 報告：零件組裝接線工作台

- 日期：2026-11-15
- 分支：`feat/f450-assembly-training`（未推送；部署另待批准）
- 依據：使用者 2026-11-15 的要求
  - 照 FPV 接線模擬器的操作方式做 F450：
    - 左邊零件欄一個一個拖進工作區，不是一開始就擺好；
    - 小手平移、可翻轉；
    - 點選零件、點引腳接線；
    - 垃圾桶刪除、可再加入；
    - 最後上電測試，接錯會「砰」。
  - 用真實零件與真實引腳定義，不用 CAD。
  - 馬達 2212，電調 20A。
- 界線：只參考對方的操作方式；畫面、圖示、音效與程式全部自製。不下載、不複製對方的程式、圖片或 Logo（P0 規則）。

## 1. 學員看到什麼

2D 接線區第二個分頁改名為「**零件組裝接線（進階：從零件欄拖入）**」。原本的「接頭級（基礎）」保留不動。

| 操作 | 做法 |
|---|---|
| 放入零件 | 從左邊零件欄拖到工作區，或按該項的「＋」（放到建議位置） |
| 平移（小手） | 按住空白處拖曳 |
| 縮放 | 滾輪、「＋／－」、「⤢ 適配」 |
| 移動零件 | 按住零件拖曳 |
| 翻轉 | 選取零件後按「↻ 旋轉」（每次 90°，引腳跟著轉） |
| 接線 | 點一根引腳，再點另一根 |
| 刪除 | 選取零件或導線後按「🗑 刪除」或 Delete 鍵；零件刪除時連到它的線一起刪，零件回到零件欄 |
| 上電測試 | 按「⚡ 上電測試」 |

**零件欄共 16 項**：
- Pixhawk 2.4.8 飛控；
- 樂迪 R9DS 接收機（SBUS 由 CH9 輸出）；
- M8N GPS／羅盤；
- 電源模組；
- 4S 鋰電池；
- F450 下中心板（配電）；
- 20A 電調 ×4（各標要接的 MAIN OUT）；
- 2212 馬達 ×4（標轉向）；
- 安全開關；
- 蜂鳴器。

## 2. 上電測試

- **有短路，而且電池有接上** → 畫面出現「砰！」爆炸圖、畫面震動、播放爆炸聲，並說明哪一根線短路、真機會怎樣。
- **沒有短路** → 依電路一路檢查，逐項列出：
  - 電源模組、配電板是否有電；
  - Pixhawk 是否開機；
  - 蜂鳴器開機音、安全開關燈；
  - GPS 搜星（TX／RX 沒交叉會指出）、羅盤；
  - R9DS 的 SBUS 訊號；
  - 四顆電調的自檢、馬達、MAIN OUT 訊號；
  - 電調紅線接到排針時另外提醒。
- **全部正確** → 「✓ 上電測試通過」，並播放開機音。
- 聲音全部用瀏覽器即時合成，不用外部音檔。可用「🔊」關閉；系統設定「減少動態效果」時不震動。

## 3. 規則與成績

- 引腳定義、54 根正確接線、錯誤判定，沿用 P11 的 `pins.js`，沒有改動。
- 成績單、3D 線束、保存紀錄沿用原流程。
- 教學、練習、考核：
  - **教學**：點引腳會標出正確的另一端；
  - **練習**：可以檢查、示範、上電；
  - **考核**：從空白開始；不能檢查、示範、上電；交卷後鎖定。
- 草稿存在 `f450twin-bench-v1`，考核不存。

## 6. 測試

工作台 25／25 通過。涵蓋：
- 一開始是空的；
- 拖入、＋加入；
- 移動、旋轉、平移、縮放；
- 刪除零件、刪除導線；
- 短路上電「砰」；
- 54 根全接對後上電通過；
- 成績單 0 → 51；
- 重新整理後保留；
- 考核清空與禁止檢查、示範、上電；
- 手機寬度不橫向捲動；
- 沒有腳本錯誤。

其他套件回歸見提交紀錄。

## 7. 仍待老師用實機核對

與 P11 相同：
1. GPS 模組端線序；
2. 電調有沒有 BEC；
3. 接頭類型；
4. R9DS 是否用 SBUS 模式、CH9 口。

另外，上電測試只是依接線推論的模擬，不代表真機一定正常。
