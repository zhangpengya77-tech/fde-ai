# F450 實訓 P14 報告：獨立全螢幕接線模擬器＋擬真零件圖

- 日期：2026-11-15
- 分支：`feat/f450-assembly-training`（未推送；部署另待批准）

## 依據

使用者回饋（附 3D 頁截圖）：「還是沒有真實，不像花生 FPV，導航界面不對」。

比對對方的手機截圖，差在兩點：
1. **入口與導覽**：對方的接線模擬器自成一頁，打開就是工作區。我們的工作台藏在 3D 數位孿生頁下方，要先往下捲，再按「開始 2D 接線練習」。
2. **零件圖**：對方是電路板實物風格。我們 P13 的零件圖太簡化。

界線不變：只參考操作方式與版面；畫面、零件圖、音效與程式全部自製，不下載、不複製對方的程式、圖片或 Logo。

## 1. 新增獨立頁 `/f450-twin/wiring.html`

**頁首**（淺色）：
- 左邊是平台圖示加「F450 接線模擬器」；
- 右邊是「◧ 3D 數位孿生」「說明」「☰ 選單」。
- 選單內容：3D 頁、練習成績、操作說明與資料來源、回平台首頁。

**工作區**：佔滿頁首以下的整個畫面。
- 左上：浮動工具列，有「＋ 配件」、↶、🗑、↻、「完整接線示例」「檔案」。
- 右上：綠色 ✓ 檢查、紅色 ⚡ 上電。
- 右下：縮放列。
- 左下：狀態與上電報告（浮動）。

**深色模式**：工作台切深色時，頁首一起變深。

**說明視窗**列出：
- 操作方式；
- 資料來源與授權（PX4 FMUv2 CC-BY-SA 3.0、PX4《Pixhawk 1》引腳表、樂迪說明書）；
- 待實機核對項目；
- 安全提醒。

**用途**：這頁是自由練習，與 3D 頁「2D 接線練習」共用同一個工作台程式與草稿。教學、考核與成績紀錄仍在 3D 頁。
