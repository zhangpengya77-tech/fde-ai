## 2. 電腦與手機：功能（40／40 通過）

5 種環境各跑同一組檢查：
- 3D 模型載入。
- 3D 組裝練習拖曳安裝零件：手機用觸控拖曳。
- 2D 接線連線：手機用點按。
- 成績單即時更新。
- 原有 5 種模式切換。
- 3D 說明條不擋視角按鈕、頁面沒有橫向捲動、沒有腳本錯誤。

## 3. 效能

| 環境 | 模型可用 | 爆炸視圖 FPS | 組裝練習 FPS | 2D 連線反應 | JS 記憶體 |
|---|---|---|---|---|---|
| Chrome 桌面 | 1.23 秒 | 41 | 60 | 51 ms | 20 MB |
| Edge 桌面 | 1.49 秒 | 42 | 60 | 42 ms | 17 MB |
| 手機 Pixel 7 | 1.12 秒 | 48 | 60 | 69 ms | 18 MB |
| 手機 iPhone 13 尺寸 | 1.16 秒 | 60 | 60 | 86 ms | 20 MB |
| 手機＋CPU 減速 4 倍 | 1.34 秒 | 59 | 60 | 213 ms | 18 MB |

- 桌面版爆炸視圖開著光暈、陰影等後製效果，所以 FPS 比手機低。手機會自動降級畫質。
- Edge 剛載入的前 3 秒 FPS 很低（3.7），觸發了既有的「自動降畫質」保護，之後恢復正常。
- 實訓模組沒有讓畫面變慢：組裝練習在 5 種環境都是 60 FPS。

## 4. 權限（Django 24／24 通過）

新增 `F450PermissionTests`：
- 學員只看得到自己的 F450 成績。
- 教師只看得到自己班級的成績；網址指定別班的班級參數也看不到。
- 教師帳號、未登入者都不能寫入 F450 成績（401），資料筆數不變。
- 學員、教師紀錄頁未登入不能看。
- 學員不能把佐證上傳到別人的 T13 任務卡（404）。

F450 頁面本身是公開頁（與原本相同），只有「保存成績」需要登入。

## 5. P7 發現並修好的問題

| 問題 | 原因 | 修正 |
|---|---|---|
| 手機上 3D 說明條擋住「實拍對照」按鈕和一大塊 3D 畫面 | 手機上視角按鈕排成兩行，說明條固定在上方 | 改放在 3D 畫面底部，手機上字較小；測試檢查不重疊 |
| 說明條內容過時：組裝練習中選的零件，切回爆炸視圖後還寫「3D 目前看不到（尚未組裝）」 | 說明只在選取當下計算一次 | 改成依「目前」狀態更新；切換模式後也補回 2D 選取的零件高亮；測試檢查 |

## 6. 沒有驗證的項目與建議

| 項目 | 原因 | 建議 |
|---|---|---|
| **iPhone Safari** | 這台電腦沒有 Safari，Playwright 的 WebKit 也沒安裝（要下載，需要你同意） | 上線前請老師或學生用 iPhone 實際開一次 F450 頁，照「拖一件零件、接一條線、按保存」走一遍；或同意我下載 WebKit 做模擬 |
| Firefox | 沒安裝 | 學生較少用；需要時同意下載後補測 |
| Android 實機、低階手機 GPU | 只能模擬 CPU 減速，無法模擬手機 GPU | 同上，實機走一遍 |
| 教室共用電腦 | 2D 接線草稿存在瀏覽器裡，下一位學生打開會看到上一位的練習草稿（考核不存草稿） | 若教室電腦共用，建議每人用自己的瀏覽器帳號，或練完按「全部清除」；要改成依登入帳號分開保存，需另外開發 |
