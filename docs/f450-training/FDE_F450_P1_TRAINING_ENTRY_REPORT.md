# F450 實訓中心 P1 報告：首頁實訓入口

- 日期：2026-11-14
- 分支：`feat/f450-assembly-training`（自正式整合版 98040d1 分出；未推送、未發布）
- 依據：P0 稽核報告 §9 的 5 項建議（使用者回覆「照建議，開始 P1」）

## 1. 範圍

在既有 F450 數位孿生頁 `/f450-twin/` 的主版面**下方**新增「無人機組裝與接線實訓」區塊，含兩個入口：

| 入口 | 類型 | 狀態 |
|---|---|---|
| A. F450 開源飛控組裝與接線 | 站內（3D 組裝、2D 接線、自動檢查、實訓考核） | 標「開發中」，按鈕停用；P2 以後開放 |
| B. FPV 穿越機接線實訓 | 外部連結 `https://hs-fpv.com/wiring-simulator` | 新分頁開啟，`target="_blank" rel="noopener noreferrer"` |

沒有改上方的模式切換（整機／爆炸／組裝／接線／尺寸）、零件列表、3D 檢視、資訊欄和尺寸卡。

## 2. 程式變更清單

| 檔案 | 變更 |
|---|---|
| `f450-twin/index.html` | `</main>` 之後、`<script>` 之前加入 `<section id="training">`（純靜態 HTML，無內嵌腳本）；`twin.css?v=1.2.0` → `v=1.2.1` 讓瀏覽器重新抓樣式 |
| `f450-twin/twin.css` | 檔尾新增 13 行 `.training`／`.train-*` 樣式，沿用既有色票（`--panel`、`--accent`、`.card`、`.tag`）；820px 以下改成單欄 |

`app.js`、GLB 模型、圖片、Django、資料庫、埠號都沒有動。

## 3. 第三方網站遵守事項（依規格）

- 只放外部連結，**不** iframe 嵌入、不下載、不鏡像、不代理、不複製其程式碼。
- **不**使用花生FPV 的 Logo 或截圖；只寫文字來源「花生FPV 公開網站（hs-fpv.com）」。
- 頁面明確寫「該網站上的操作不會自動記錄到本平台」；學員需匯出 PNG 回本平台任務卡上傳，由教師審核。上傳功能屬 P6（任務卡／證據），P1 只寫說明文字。

## 4. 測試結果

| 項目 | 方法 | 結果 |
|---|---|---|
| 桌面版 1440px 版面 | headless Chrome 截圖（`P1_desktop_1440.png`） | 通過：3D 模型正常載入，零件列表、資訊欄、尺寸卡與原本相同；實訓區在下方兩欄並排 |
| 手機版 390px 版面 | 390px iframe 截圖（`P1_mobile_390.png`） | 通過：實訓區單欄、外部連結按鈕滿寬、無橫向捲動；上方模式列與 3D 正常 |
| 既有腳本不受影響 | 檢查 `app.js` 所有 `querySelectorAll`：都限定在 `#layer-chips`、`#step-list`、`#check-list` 等既有容器或 `[data-mode]`／`[data-view]`／`[data-wire]` 屬性 | 通過：新區塊沒有這些屬性，不會被綁定 |
| 外部連結屬性 | 原始碼檢查 | `target="_blank" rel="noopener noreferrer"` |

未驗證：

- 沒有在正式站（8140／8772）上測；P1 只在隔離分支的檔案上驗證。
- 沒有逐一點擊五種模式做互動回歸（腳本與 DOM 結構未改，只靜態確認）；P7 整體回歸時補做。
- 外部網站本身的可用性與匯出功能沒有實測（依規格不自動化操作第三方網站）。

## 5. 風險

| 風險 | 程度 | 處理 |
|---|---|---|
| 外部網站改網址或下線 | 中 | 連結失效時只影響入口 B；教師可改 `href` 一處 |
| 學員誤以為入口 A 已可用 | 低 | 標「開發中」並停用按鈕 |
| CDN／瀏覽器快取舊 CSS | 低 | 已更新 `?v=1.2.1` |

## 6. 回滾方案

P1 只有一個提交。正式站尚未發布，因此回滾只需在分支上：

```bash
git revert <P1 提交>
```

若日後已發布，把 `f450-twin/index.html`、`f450-twin/twin.css` 換回 98040d1 版本即可，沒有資料庫或設定變更。
