# 即時鏡頭檢測：手機 HTTPS 本機測試方式

手機瀏覽器只會在「安全連線」下開放鏡頭，也就是 HTTPS，或電腦自己的 `localhost`。
用 `http://電腦IP:埠號` 從手機開頁面時，鏡頭會被瀏覽器擋下，頁面會顯示「手機鏡頭需要 HTTPS 連線」。
下面兩種方法任選一種。

> 安全提醒
> - 測試時只用測試帳號與測試資料。
> - 測完要關閉通道或伺服器。
> - 不要把正式站的金鑰放進測試環境。

---

## 方法 A：Cloudflare 快速通道（最簡單，不用裝憑證）

本機已安裝 `cloudflared`（`C:\Program Files (x86)\cloudflared\cloudflared.exe`）。

1. 在電腦上啟動要測試的網站，例如預覽環境的入口埠。下面的 `<埠號>` 換成實際的埠。
2. 開一個 PowerShell 視窗，執行：

   ```powershell
   cloudflared tunnel --no-autoupdate --url http://127.0.0.1:<埠號>
   ```

3. 畫面會出現一行 `https://xxxx.trycloudflare.com`，用手機開這個網址。
4. 登入學員帳號 → 鷹眼 AI 檢測中心 → F450 槳葉檢查 → 「即時鏡頭」→ 開始鏡頭檢測。手機會詢問相機權限，按允許。
5. 測完在 PowerShell 按 `Ctrl+C` 關閉通道。

注意：
- 快速通道的網址任何人都能開，測完請立刻關閉。
- 這個網址不在網站的允許主機清單裡，Django 可能會擋下請求。如果出現 400 或 CSRF 錯誤，請改用已設定好的預覽環境，例如 `D:\FDE-AI-Runtime\v2-about` 那組，它的通道網址已經加進允許清單。

## 方法 B：Caddy＋本機憑證（只在同一個 Wi-Fi 內，不對外）

1. 安裝 Caddy：

   ```powershell
   winget install CaddyServer.Caddy
   ```

2. 查電腦在區域網路的 IP，例如 `192.168.1.20`：

   ```powershell
   ipconfig
   ```

3. 啟動 HTTPS 反向代理，讓手機透過 `https://192.168.1.20:8443` 連到本機網站：

   ```powershell
   caddy reverse-proxy --from https://192.168.1.20:8443 --to http://127.0.0.1:<埠號> --internal-certs
   ```

4. 讓手機信任 Caddy 的本機憑證：
   - 憑證位置：`%AppData%\Caddy\pki\authorities\local\root.crt`
   - iPhone：把 `root.crt` 傳到手機 → 設定 → 一般 → VPN 與裝置管理 → 安裝描述檔 → 再到「一般 → 關於本機 → 憑證信任設定」打開完整信任。
   - Android：設定 → 安全性 → 加密與憑證 → 安裝憑證 → CA 憑證。
5. 用手機開 `https://192.168.1.20:8443`。
6. 測完按 `Ctrl+C` 關閉 Caddy。不再需要時，請到手機設定移除這張測試憑證。

## 手機上要確認的項目

- 預設開啟後置鏡頭；「切換鏡頭」可以換到前鏡頭。用前鏡頭時畫面可能左右鏡像，判定可能顯示「四支全反」並附上鏡像提醒，這是預期行為。
- 推論尺寸固定 640（2026-11-08 決定）。手機較慢時，畫面上的判定會跳幀更新，FPS 顯示在畫面左上角。
- 「省電模式」只降低鏡頭擷取解析度（640×480）和每秒推論次數（最多 5 次），不會降低推論尺寸。
- 切到其他 App 或鎖螢幕，鏡頭會自動關閉，回來後需要再按一次「開始鏡頭檢測」。
- 畫面只在手機上辨識，不會上傳到伺服器。可以用瀏覽器開發者工具的「網路」頁確認：只有一開始下載模型，之後沒有上傳畫面的請求。

## 已知限制

- iPhone 需要 iOS 16.4 以上（Worker 內要用 OffscreenCanvas）；較舊的系統會顯示「辨識模型無法在這台裝置上執行」。
- 沒有 WebGPU 的手機會改用 WASM，速度明顯較慢，640 解析度大約每秒 1～2 次。
- 第一次使用要下載約 10 MB 的模型和約 22 MB 的推論程式，建議在 Wi-Fi 下進行。
