## 一、登入與選班級（步驟 1–2）

1. 開瀏覽器 → 輸入教師後台網址 → 輸入帳號密碼 → 送出。
2. 後台首頁會看到四個入口：**班級學習成果總覽**、**班級成果報告**、**結訓審核清單**、**班級成果展示中心**。
3. 每一頁上方都有「班級」下拉選單，選好後按「切換班級」。

> **看不到某個班級是正常的**：系統只授權你檢視自己帶的班。這是權限保護，不是故障。

---

## 二、查看成果（步驟 3–5）

### 步驟 3：待複核成果（班級學習成果總覽）

四張統計卡：

| 卡片 | 意思 |
|---|---|
| 班級學員（人） | 這個班目前有幾位在學學員 |
| **待複核成果（筆）** | 學員已交、**還在你手上等你複核**的成果筆數 |
| 尚未提交（人） | 八項成果一項都還沒交的人數 |
| 已完成八項（人） | 八項都已有教師複核結果的人數 |

下方是**待複核清單**與**學員進度列表**，可依紀錄（R01–R08）、類型、狀態、排序做篩選。

> **重要**：「待複核成果（筆）」是**筆數**；學員篩選的「有待複核成果」是**人數**。兩者用同一份資料，只是單位不同。

### 步驟 4：結訓審核清單

一眼看出「誰還沒交、誰還在等我複核、誰需要補充」。每一筆待處理項目都連到**既有的教師審核頁**，複核完就回到清單。

> **本清單不自動判定學員合格或結訓通過，也不核發任何證照。** 判斷權在教師。

### 步驟 5：班級成果報告

彙整班級基本資料、成果摘要、五階段概況、R01–R08 成長成果、學員成果與教師回饋，可用瀏覽器列印成 A4 報告。

> **「八項已提交」不等於「八項通過」**；「證」階段是**課程學習成果紀錄**，不是民航局專業操作證。報告不含假成績、假照片、假證照或自動生成的教師評語。

## 三、匯出 CSV（步驟 6）

在報告頁或清單頁按兩個匯出鈕：

| 按鈕 | 內容 |
|---|---|
| **匯出班級統計摘要** | 一班一列的統計數字 |
| **匯出學員成果明細** | 一位學員一列的成果明細 |

- 兩份都使用 **UTF-8 BOM**，Windows Excel 直接雙擊開啟，繁中不亂碼。
- 已防止公式注入（`=`、`+`、`-`、`@` 開頭的內容會被安全處理）。
- **不匯出** Email、電話、密碼或 Token 等個資，也**不打包**私人證據原始檔。

---

## 四、成果展示（步驟 7–8）

1. 進入「班級成果展示中心」，往下確認七頁內容是否符合你的認知。
2. 按 **「開始展示」** 進入簡報模式。

| 操作 | 方式 |
|---|---|
| 下一頁 | `→`、`PageDown`、空白鍵，或下方按鈕 |
| 上一頁 | `←`、`PageUp`，或下方按鈕 |
| 第一頁／最後一頁 | `Home`／`End` |
| 結束展示 | `Esc`，或「結束展示」按鈕 |

**投影機**自動維持 16:9；**手機**改為填滿螢幕、按鈕加大。

> **iPhone 提示**：Safari 不支援整頁全螢幕，畫面仍正常播放，只是上方可能還看得到網址列。

### 匿名是預設，也是建議

- **系統預設匿名化展示**（綠色標籤）：學員以「學員 01／02」呈現，**不顯示姓名、識別碼、評語內容與作品照片**。
- 要顯示姓名或照片，必須先取得學員（或其監護人）同意，再按「我已取得授權，開啟具名展示」。
- **系統只記錄你的聲明，不替你查核授權；責任在教師。**
- 授權**逐班分開**，且**登出即失效**。

---

## 五、退出與登出（步驟 9）

1. 按 `Esc` 退出簡報，回到一般檢視。
2. 若曾開啟具名展示，請按「改回匿名化展示」（或直接登出）。
3. 按右上角 **「登出」**。

> 登出後，你的頁面連結**無法被他人直接開啟**，會自動跳回登入頁。

## 六、常見問題

| 情況 | 說明 |
|---|---|
| 某處顯示「尚無紀錄」 | 該項目目前確實沒有任何紀錄，不是系統壞掉。 |
| 匿名模式下看不到評語內容 | 刻意設計（評語可能含學員姓名）。仍會顯示「本班目前共 N 筆評語」。 |
| 選單裡沒有某個班級 | 系統未授權你檢視該班，屬正常權限保護。 |
| CSV 打開是亂碼 | 請用 Excel 直接雙擊開啟（勿用記事本另存）；檔案已含 UTF-8 BOM。 |
| 按了「開始展示」沒有全螢幕 | iOS Safari 不支援整頁全螢幕，畫面仍可正常播放。 |
| 換班級後變成匿名了 | 授權逐班分開，刻意設計。 |

---

## 七、教師不可以做的事（系統保護）

- 系統**沒有**公開分享連結功能，也**不開放**未登入者觀看。
- 系統**不會**把學員作品複製到公開資料夾。
- 系統**不會**自動產生評語、成績或證照。
- 系統**不會**把「已提交」寫成「已通過」。
- 教師**只能**看到自己帶的班級。

---

## 八、給非技術教師的三句話

1. **先選班級，再看數字。** 所有頁面的數字都來自同一份紀錄，互相一致。
2. **預設就是匿名，直接開始展示最安全。** 要顯示姓名或照片前，先確認已取得同意。
3. **用完請 `Esc` → 切回匿名 → 登出。**
