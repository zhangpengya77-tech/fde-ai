## 一、這頁是做什麼的

「班級成果展示中心」把一個班級的學習成果整理成 **7 頁投影片**，可以在課堂、家長會或成果發表時直接投影播放。

七頁依序是：

| 順序 | 頁面 | 內容 |
|---|---|---|
| 1 | 封面 | FDE-AI-UAS 品牌與班級名稱 |
| 2 | 班級成果 | 班級學員人數與整體統計 |
| 3 | 五階段概況 | 學 → 練 → 做 → 測 → 證 各階段完成情形 |
| 4 | R01–R08 | 八個任務紀錄的真實提交與複核數 |
| 5 | 學員作品 | 學員成果與既有證據 |
| 6 | 教師回饋 | 教師已複核的成果與評語 |
| 7 | 結語 | 班級總結 |

> **重要用語**：畫面上的「已提交」**不等於**「已通過」；「證」階段是**課程學習成果紀錄**，不是民航局專業操作證。系統不會自動生成任何評語或成績。

## 二、操作流程（六步）

```
登入教師後台 → 選擇班級 → 檢查成果 → 選擇展示模式 → 開始展示 → 結束展示
```

### 步驟 1：登入

| 項目 | 內容 |
|---|---|
| 網址 | `http://<主機位址>/teacher/login/` |
| 操作 | 輸入教師帳號與密碼 → 送出 |
| 成功後 | 進入教師後台首頁 |

### 步驟 2：進入展示中心

在教師後台首頁找到 **「班級成果展示中心」**，點進去。
頁面上方有一個「班級」下拉選單，選擇要展示的班級。

> 您只能看到**自己帶的班級**。若選單裡沒有某個班級，代表系統未授權您檢視該班，這是正常的權限保護。

### 步驟 3：檢查成果

往下瀏覽七頁內容，確認數字與內容符合您的認知：

- 學員人數是否正確？
- 五階段與 R01–R08 的提交／複核數是否合理？
- 有沒有「尚無紀錄」的空狀態？那代表該項目**目前確實沒有任何紀錄**，不是系統壞掉。

若發現數字與預期不符，請先回到對應的紀錄頁確認學員是否真的完成提交與複核。

### 步驟 4：選擇展示模式（**最重要的一步**）

頁面上方有一條**隱私列**，顯示目前的展示模式：

| 模式 | 畫面顯示 | 會顯示什麼 |
|---|---|---|
| **匿名化展示（預設）** | 綠色標籤 | 學員以「學員 01／02…」呈現；**不顯示姓名、識別碼、教師評語內容與作品照片** |
| **具名展示** | 黃色標籤 | 顯示學員姓名與作品證據 |

**系統預設為匿名化展示。** 這是為了保護學員個資。

#### 什麼時候可以用具名展示？

只有在您**已經取得該班學員（或其監護人）同意**時，才可以開啟具名展示。

開啟時請按「我已取得授權，開啟具名展示」，畫面會出現黃色提示：

> **具名展示＝教師確認已取得必要授權。本系統無法查核授權來源，開啟與否由教師自行負責；請確認已取得學員（或其監護人）同意後再開啟。**

也就是說：**系統只記錄您的聲明，不會替您查核授權。** 責任在教師身上。

#### 授權是「一個班級一個班級」分開的

- 您為甲班開啟具名展示，**不會**讓乙班也變成具名。
- 切換到其他班級時，該班仍維持匿名化展示。
- **登出或關閉瀏覽器後，授權狀態即失效**，下次登入需重新確認。

#### 隨時可以改回匿名

按「改回匿名化展示」即可立即恢復預設，不需要任何額外設定。

### 步驟 5：開始展示

按 **「開始展示」**，畫面會進入全螢幕簡報模式。

| 操作 | 方式 |
|---|---|
| 下一頁 | 鍵盤 `→`、`PageDown`、空白鍵，或畫面下方「下一頁」按鈕 |
| 上一頁 | 鍵盤 `←`、`PageUp`，或畫面下方「上一頁」按鈕 |
| 第一頁／最後一頁 | 鍵盤 `Home`／`End` |
| 結束展示 | 鍵盤 `Esc`，或畫面下方「結束展示」按鈕 |

**投影機**：畫面會自動維持 16:9 比例（與大多數投影機相同），不會被拉變形。

**手機**：手機上不套用 16:9（會太小），改為填滿整個螢幕，操作按鈕加大到好按的尺寸。

> **iPhone 提示**：Safari 不支援把整頁變成全螢幕（只有影片可以）。按「開始展示」後畫面仍會正常呈現，只是上方可能還看得到瀏覽器網址列，這是正常的。

### 步驟 6：結束展示

按 `Esc` 或「結束展示」即可回到一般檢視頁面。此時**不會**自動把具名改回匿名——若您已開啟具名展示，請記得手動按「改回匿名化展示」（或直接登出）。

## 三、常見問題

| 情況 | 說明與處理 |
|---|---|
| 某頁顯示「尚無紀錄」 | 該項目目前確實沒有任何紀錄，不是錯誤。 |
| 匿名模式下看不到評語內容 | 這是刻意設計（評語可能含學員姓名）。畫面仍會顯示「本班目前共 N 筆評語」。 |
| 選單裡沒有某個班級 | 系統未授權您檢視該班，屬正常權限保護。 |
| 作品照片顯示不出來 | 可能是原始檔案已被移除。其他內容與整場展示不受影響。 |
| 按了「開始展示」但沒有全螢幕 | iOS Safari 不支援整頁全螢幕；畫面仍可正常播放。 |
| 換班級後變成匿名了 | 授權是逐班分開的，這是刻意設計。 |
| 登出後又要重新開啟具名 | 授權存在登入狀態中，登出即失效，這是刻意設計。 |

## 四、教師不可以做的事（系統保護）

- 系統**沒有**「公開分享連結」功能，也**不開放**未登入的人觀看。
- 系統**不會**把學員作品複製到公開資料夾。
- 系統**不會**自動產生教師評語、成績或證照。
- 系統**不會**把「已提交」寫成「已通過」。

---

## 五、給非技術教師的三句話總結

1. **預設就是匿名，直接開始展示最安全。**
2. **要顯示姓名或照片前，先確認你已經拿到學員同意，再按「開啟具名展示」。**
3. **展示完請按 `Esc`，並記得切回匿名或登出。**
