## 若「Load failed」的快速自查（非缺陷情境）

1. 手機與電腦是否同一 Wi-Fi（區網 IP 是否仍為 `192.168.1.114`，命令列 `ipconfig`）。
2. DEMO 服務是否仍在（重跑 `demo\tools\start_demo.ps1 -NoBrowser`；**勿手動拼環境變數**）。
3. 電腦防火牆是否允許區網連入 8110／8111。
4. 都不是才記為異常。
