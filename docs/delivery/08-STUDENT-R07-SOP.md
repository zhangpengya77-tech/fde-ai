### 7.2 失敗

畫面顯示：

```
模型提交失敗，請確認 Vision 服務後重試。
```

**處理**：
1. 請教師確認 Live Backend（:8030）已啟動
2. 確認後重新提交

> **失敗時系統會完整回滾**：
> - 0 筆 Evidence
> - 0 筆 `VisionModelRecord`
> - submission 狀態維持 `not_started`
>
> **不會留下半完成的資料。** 學員可安心重試。

## 十、提交後發生什麼（學員可見的後續）

```
學員提交 best.pt
  ↓
[Django] 建立 Evidence 記錄
  ↓
[Django] POST → Live Backend /api/v1/vision/submissions
  ↓
[Live Backend] 寫入 Vision Center JSON Store
  ↓
[Django] 記錄 vision_submission_id（雙向 binding）
  ↓
狀態：等待教師審核
  ↓
教師審核（退回補件 / 列為候選）
  ↓
教師收藏 → 建立不可變快照 → 進入模型倉庫
```

### 10.1 SHA256 四層一致（實測）

| 層 | 內容 |
|---|---|
| 學員原始檔 | `ad49fc6c602badb8929a9b5949f8592f253e25d9673bc277cdb79362df710207` |
| Django MEDIA 儲存 | **相同** |
| JSON Store `file_hash` | **相同** |
| Repository `snapshot_sha256` | **相同** |

> 學員可放心：**檔案在傳輸與儲存過程中未被修改。**
