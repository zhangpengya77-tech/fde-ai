# CW / CCW 槳葉與馬達檢查

本文件說明 F450 的 CW 正槳、CCW 反槳、馬達方向與 AI 檢測注意事項。

## 基本概念

- CW 表示順時針方向。
- CCW 表示逆時針方向。
- 四軸無人機需要兩片 CW 槳與兩片 CCW 槳交錯安裝。
- 槳葉安裝錯誤會造成無人機無法穩定起飛，甚至翻機。

## 檢查方式

檢查槳葉時，要同時確認三件事：

1. 馬達位置是否正確。
2. 馬達旋轉方向是否正確。
3. 該位置安裝的是 CW 還是 CCW 槳。

只看槳葉文字不一定足夠，還要看槳葉弧度、前緣方向與馬達旋轉方向。

## AI 檢測提醒

AI 目標檢測可以協助辨識槳葉、馬達與機臂，但若圖片角度太斜、反光嚴重、槳葉被遮住或畫面模糊，仍需要人工確認。

若 AI 顯示 WARNING，學生應重新拍攝清楚照片，並請老師確認。
