# 鏡頭＋原子筆、手機、手勢測試紀錄

## 實作現況（沿用 FDE 既有實作，本次未改寫）
| 連線方式 | 實作 | 影像處理位置 | 本次狀態 |
|---|---|---|---|
| 🖊️ 原子筆＋鏡頭 | `src/input/pen/pen-tracker.ts`：點一下筆蓋取色 → 每格縮成約 160×120 找相近顏色像素 → 重心＝筆尖位置、像素量＝遠近；右手一支＝前後左右、左手第二支不同色＝油門與轉向 | 只在瀏覽器本機，不錄影、不上傳 | 🟡 已接到新引擎；**只追位置與遠近，沒有筆身傾斜辨識**；與參考站「白筆身藍筆尖、兩支筆立著當搖桿」的辨識方式不同 |
| ✋ 手勢 | MediaPipe Hand Landmarker（Apache-2.0），手掌移動＝搖桿、握拳＝懸停 | 本機 | ✅ 保留，已接到新引擎 |
| 📱 手機遙控器 | WebRTC，配對碼／QR，經 `fde-ai-v2` 固定入口的 `/api/simlink` 交換訊號 | — | 🟡 **需要教學主機開機**；教師電腦關機時無法配對 |

## 自動測試
- `tests/unit/pen-tracker.test.ts`（既有）：取色、重心、遠近、失去追蹤 → 單元測試全數通過（全套 847 項通過，見 DEPLOYMENT_REPORT.md）。
- 新版考照入口的瀏覽器測試確認五種連線方式的說明與既有浮動「🔗 連線方式」面板都還在。
- **鏡頭與手機無法在自動化環境驗證實際辨識精度與延遲。**

## 需人工驗收
| 步驟 | 預期 | 結果 |
|---|---|---|
| 筆電鏡頭，按「🔗 連線方式」→ 原子筆 → 開鏡頭，選鏡頭 | 看得到畫面 | ☐ |
| 點筆蓋取色，移動右手筆 | 右搖桿點跟著動；飛機前後左右移動 | ☐ |
| 筆移出畫面 | 失去追蹤 → 自動懸停 | ☐ |
| 第二支不同顏色的筆 | 控制油門與轉向，能起飛 | ☐ |
| 手機掃 QR（教學主機開機、同 Wi‑Fi） | 配對成功，雙拇指可飛 | ☐ |
| 手機關掉螢幕 | 0.25 s 後懸停 | ☐ |

## 已知限制（如實揭露）
- 原子筆精度受光線與筆蓋顏色影響，背景有同色物體時可能誤判。
- 尚未實作參考站的「筆身傾斜當搖桿」與追蹤信心值顯示。
