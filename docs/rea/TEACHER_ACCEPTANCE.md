# 教師人工驗收步驟（REA 考照模擬器）

網址（部署後）：https://zhangpengya77-tech.github.io/fde-ai/v2/sim/ → 「開始考照模擬練習」
（直接網址：…/v2/sim/app/?mode=exam&exam=0；舊版：…/v2/sim/app/?mode=exam-legacy&exam=0）

建議環境：Windows Chrome／Edge，筆電＋RadioMaster Pocket（USB Joystick HID）。

## 1. 入口與版面（5 分鐘）
- [ ] 仿真訓練頁仍有兩張卡片（考照、電力巡檢）與「五種操作方式」說明。
- [ ] 進入考照：右側是「臺灣無人機考照模擬器」，有考試科目／趣味挑戰、證照篩選、三種機型、考場設定。
- [ ] 上方已不是舊 F450 考照介面；舊版仍可從「舊版 F450 考照（歷史版本）」開啟。
- [ ] 手機直向開啟：上方 3D、下方面板，不需左右捲動。

## 2. 示範與評等（10 分鐘）
- [ ] 選「8 字水平圓」→「看示範」：機體從 H 起飛，飛到 P4，左圈逆時針、右圈順時針，倒退回 H。
- [ ] 飛完出現練習評等（頂尖／標準／擦邊／失敗）、逐段指標、「不是民航局官方評分」說明。
- [ ] 回放：▶、×1／×1.5／×3／×6、拖曳時間軸、「看這段」可跳到該步驟。
- [ ] 俯視軌跡可切換「照時間／照偏離航線／照機頭偏差」上色。
- [ ] 依序看「四面停懸」「側飛」「五邊」「緊急返航」「矩形航線」「I2 小場地」示範，路線符合 AC 107-005D。

## 3. USB 遙控器實機（15 分鐘，**必做**）
依 `USB_CONTROLLER_TEST.md` 第 B 節逐項打勾，特別是：
- [ ] 美國手四個方向正確；機頭朝內時左右相反（符合真機）。
- [ ] 日本手：右手油門。
- [ ] 飛行中拔 USB → 懸停不墜機。
- [ ] 自己飛一次四面停懸，拿到評等。

## 4. 其他連線方式（10 分鐘）
- [ ] 鍵盤：W/S 前後、A/D 左右、Q/E 轉向、R/F 升降。
- [ ] 原子筆＋鏡頭、手勢：依 `CAMERA_PEN_TEST.md`。
- [ ] 手機遙控器：需教學主機開機、同 Wi‑Fi；教師電腦關機時應如實無法配對。

## 5. 回歸檢查（5 分鐘）
- [ ] FDE-AI 首頁、公開課程、F450 數位孿生、下載中心正常。
- [ ] 電力巡檢場景仍可進入。
- [ ] 登入、教師後台、學員上傳不受影響（本次未修改任何後端）。
