## P0 檢查結果

- **平台頁 `/platform/`** 由 Django `learning.views.platform_entry`／`platform_asset` 提供：
  - 讀取的是正式站資料夾根目錄的 `index.html`；
  - 自動注入 `<base href="/platform/">`；
  - 任何沒有副檔名的子網址都回首頁 HTML，`src/` 底下的檔案直接提供。
  - 因此**不需要改 Django 或資料庫**。
- **技術棧**：靜態 HTML＋原生 JavaScript（沒有框架）。
  - 路由用 `src/router.js` 的 `FdeRouter`（依網址最後一段對應頁面）；
  - 導航由 `src/app.js` 的 `renderNavigation()` 產生，手機抽屜選單也同步這份。
- **部署方式**：正式站資料夾 `D:\FDE-AI-UAS-v2.0-integration` 用 git 快轉更新。改的是靜態檔，不需要重啟服務。
- **GitHub Pages 靜態版**（`public-site/v2/`）：
  - 是另一份平台副本，版本不同、用的是另一個分支；
