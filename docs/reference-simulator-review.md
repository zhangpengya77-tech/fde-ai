## 3. 科目名稱與台灣 CAA 基本級之差異

> 本節依**公開考照體系差異**分析，非取自凌動內部。凌動若為中國 CAAC 體系，其科目與台灣 CAA 不同。台灣側科目名稱依使用者先前指示（來源：民航通告 AC 107-005 系列，我方正建 config）。

### 3.1 台灣 CAA 專業基本級（多旋翼）科目（依據：AC 107-005 附錄）

1. 定點起降及四面停懸
2. 八字水平圓
3. 側面停懸及前進後退（含機頭朝右）
4. 高度保持五邊飛行
5. 緊急程序處置
6. 飛行前後檢查

### 3.2 凌動（疑似 CAAC 中國體系）常見科目 — ⏳ 待截圖確認

依中國民用無人機駕駛員（CAAC / AOPA）多旋翼視距內常見術科項目推測（**非取自該軟體，待截圖核對**）：

- 定點起降 / 垂直起降
- 四面懸停（對尾 / 對左 / 對右 / 對頭）
- **水平 360° 自旋** ← 疑似 CAAC 專有
- 水平八字飛行
- 慢速水平 360° 自旋 / 航線飛行（依級別）

### 3.3 差異對照與納入判斷

| 科目 | 台灣 CAA 基本級 | 凌動（疑似 CAAC） | 我方處置 |
|---|---|---|---|
| 定點起降 | ✅ | ✅（推測） | **納入**（第一階段） |
| 四面停懸 | ✅（四面停懸） | ✅（四面懸停） | **納入**（第一階段） |
| 八字水平圓 | ✅ | ✅（水平八字） | **納入**（第一階段） |
| 側面停懸及前進後退（含機頭朝右） | ✅ | ❓（待確認） | **納入**（第二階段介面） |
| 高度保持五邊飛行 | ✅ | ❓ | **納入**（第二階段介面） |
| 緊急程序處置 | ✅ | ❓ | **納入**（第二階段介面） |
| 飛行前後檢查 | ✅ | ❓ | **納入**（第二階段介面） |
| **水平 360° 自旋** | ❌ 台灣基本級無此項 | ✅（疑似 CAAC 專有） | **不納入**（標為 CAAC 專有，來源差異） |
| 航線飛行 / 其他 CAAC 專有項 | ❌ | ⚠️ 待截圖 | **不納入**（除非使用者另有指示） |

> 結論：**「水平 360° 自旋」標為疑似 CAAC 專有項，不納入我方台灣 CAA 基本級模擬**。其餘以台灣 CAA 基本級科目為準，自行設計。
