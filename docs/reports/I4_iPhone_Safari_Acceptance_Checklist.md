# FDE-AI-UAS 2.0｜iPhone Safari 人工驗收表（I4-E）

> 本表供教師以**真實 iPhone** 逐項照做。
> 在教師回填本表並附上實機截圖之前，所有手機相關結論一律為 **`PENDING`**，
> 不得以 Chrome 裝置模擬（390×844）之結果宣稱為真機通過。

- 專案：`D:\FDE-AI-UAS-v2.0`
- 對應指令：教師 I4 指令第七節
- 驗收等級定義：
  - `AUTOMATED PASS`：單元測試 + 隔離 HTTP 驗收 + Chrome 裝置模擬通過（已完成）
  - `REAL DEVICE PASS`：**本表全部項目於 iPhone 實機通過**（尚未取得）

## 一、前置準備（約 3 分鐘）

| # | 步驟 | 指令／動作 | 預期 |
|---|---|---|---|
| P1 | 啟動 DEMO 服務 | 於專案根目錄雙擊 `START_FDE_2_DEMO.cmd`（或執行 `demo\tools\start_demo.ps1 -NoBrowser`） | 主控台顯示「DEMO 已就緒」，所有展示頁面檢查通過 |
| P2 | 確認手機與電腦同一網段 | 電腦區網 IP 為 `192.168.1.114` | iPhone Wi-Fi 與電腦同一個路由器 |
| P3 | 取得登入密碼 | 開啟 `%USERPROFILE%\.fde-demo-credentials\demo.shared.password.txt` | 取得學員／教師共用密碼 |
| P4 | 確認 RAG 服務（AI 助教問答用） | 電腦上 `:8770` 是否在執行 | 未執行時第 4 站「AI 助教問答」會顯示明確的離線訊息（屬預期降級，非缺陷） |

> ⚠️ 本表只使用 **DEMO 隔離環境（:8110 / :8111）**，不會接觸正式服務（:8022 / :8770）與正式資料庫。

## 四、已知且屬預期的現象（不需回報為缺陷）

1. **RAG 未啟動時**第 4 站問答會顯示「FDE 知識庫暫時無法連線」——這是刻意的降級設計，不影響學習紀錄與教師審核。
2. **外部模組卡片固定顯示「尚未接入」**——MP 地面站／HQGC／F450 3D 數位孿生本輪僅預留接口，尚未由教師獨立專案接入。
3. **AI 語音朗讀**需使用者手勢觸發（iOS Safari 限制），按下朗讀鈕才會發聲。
4. **首次載入工作台**會補齊該課程的進度列，屬既有行為。
