# 六類 3D 實驗報告

所有實驗都有「重新開始」「全螢幕」「返回課程」，完成判定後保存紀錄（`store.saveLab`），並把對應單元的「實驗任務」「3D 實驗」步驟打勾。

| 實驗 | 功能 | 完成判定 | 自動化測試 |
|---|---|---|---|
| A 拆解 | 360° 旋轉縮放、透明機殼、爆炸圖滑桿、零件名稱標籤、點選說明、拖放組裝（手機：點零件再點畫面） | 全部 17 個零件裝回 | PASS |
| B 姿態 | Pitch／Roll／Yaw／Throttle 滑桿，鍵盤與 USB 遙控器同步；機頭紅箭頭；M1–M4 轉速示意；4 個任務（保持水平、Yaw 90°、前傾 15°、左滾 20°） | 4 任務全完成（第 1 項完成即算單元任務） | 任務 1 PASS |
| C 電池 | 串聯 1–6S、並聯 1–3P、單芯電壓 3.0–4.35 V、容量選擇；電流路徑動畫；充放電離子動畫；過充鼓包；過充／過放示警 | 試過單體、3S、4S、6S、4S2P | PASS |
| D 無刷電機 | 外轉子 12 槽 14 極：定子、線圈（三相上色）、轉子鐘罩、14 片磁鐵、轉軸、軸承、底座；爆炸圖；六步換相按鈕／自動播放；磁場箭頭；轉子依 1/7 比例轉動 | 六步都走過 | PASS |
| E F450 組裝 | 連到既有組裝實訓室 R2.1（零件拖放、Pixhawk 2.4.8 接線、電機方向、錯誤檢查、評分）＋本頁電機編號轉向檢核 | 檢核全對 | PASS（組裝實訓室本身另有 43 項測試 PASS） |
| F 感測器 | 傾斜滑桿、外力推動、陀螺儀／加速度計讀數、即時曲線、PD 自穩可調 P、D | 傾斜 ≥20° 後開自穩回到 ±2° | PASS |

## 限制
- 3D 外形為教學用簡化模型，不是真實零件 CAD。
- 實驗 E 的完整組裝分數保存在組裝實訓室自己的紀錄，青少年實驗室只記錄「電機編號檢核」。
- 幀率只在無頭瀏覽器（軟體繪圖）量過，實機平板／手機幀率**未量測**。
