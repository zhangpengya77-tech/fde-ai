# 無人機足球 3D 專項訓練：測試報告

**飛行模型是「教學級運動學近似」，不是經驗證的真實飛行物理**（畫面右下角固定標示）。高度保持式操作：油門＝爬升率、俯仰／橫滾＝目標水平速度（最大 4 m/s），一階反應時間 0.35 秒；網籠邊界碰撞速度歸零。

## 任務
| 任務 | 判定 | 測試 |
|---|---|---|
| 自由練習 | 不計分 | 模式切換 PASS |
| 定點飛行 | 中圈上方 1.5 m ±15 cm、水平 0.5 m 內累積 10 秒 | 判定函式單元測試 PASS；瀏覽器內**手動操作未自動化** |
| 穿越球門 | 由場內往外穿過紅隊圓環（半徑 0.65 m） | 鍵盤操作 PASS（約 5 秒，成績已保存） |
| 進攻路線 | 依序經過 3 個路線點再穿門 | 模式切換 PASS；完整路線**未自動化** |
| 防守戰術 | 紅隊得分機沿路線衝門，攔截（距離 <0.9 m）成功；它穿門則失敗 | 未攔截→判定失敗 PASS；攔截成功**未自動化** |
| 計時挑戰 | 60 秒倒數，穿門得分後須回中線左側才能再得分 | 模式切換 PASS |

## 其他
- 3 對 3 名單、選中球機、課堂預設 3 種戰術、俯視點場地加路線點、保存／讀取／清除：PASS（預設＋演示）。
- 視角：全景、俯視、側視、飛手視角、跟隨：PASS。
- 單元測試：運動模型上升、邊界、緊急停止後不可上升、穿門幾何判定（含從圓環上方飛過不算）：PASS。
- 效能：無頭 Chromium（SwiftShader 軟體繪圖）約 10 fps；這不是實機數字，實機待量測。
