## 3. 課程卡片與導航
- 卡片：上半封面（漸層色＋燒杯圖示的實驗卡，或插畫課程卡），下半標題＋說明＋藍色「開始實驗／開始學習」按鈕。
- 頁首右側固定三鈕：「重新開始」「全屏實驗」「返回／關閉實驗」。

## 4. 互動式知識講解（飛行訓練三欄頁，最核心的版型）
- 左欄：章節列表（目前章節藍底高亮）。
- 中欄：大標題（例：看清起降動作，也看清學生站位）＋ 3D 場景（視角按鈕：三維視角／俯視／側視／機頭跟隨／駕駛），右上角即時數值卡（目前高度 0.00 m），下方動作分段時間軸（01 解鎖、02 起飛、03 懸停、04 降落…）與「播放演示／速度」。
- 右欄：目前動作卡（名稱、說明、時間）＋「觀察與站位」數值（距離、高度範圍、水平誤差）。
- 考核標準頁：3 張大數字卡（例 1.5 m±15 cm、≤15 cm、≤2 秒）＋完整動作要求清單＋「課堂判定：教師觀察」。
- 訓練技巧頁：01／02／03 三欄技巧卡。

## 5. 3D 模型展示與操作
- 3D 實驗頁上方視角切換鈕，可拖曳旋轉；模型為卡通化簡化外形（人物、無人機、風扇、起降坪）。
- 組裝影片（第二支）：白色網格地面＋左側零件清單（打勾表示已裝）＋底部步驟分頁；零件爆炸圖、單件拖入、接線圖模式（深灰背景、焊點十字標記、彈窗說明排線對接）。→ 與本平台既有「組裝實訓室 R2.1」功能高度重疊，**直接沿用既有實作**。

## 6. 電池串並聯實驗
- 上方分頁：01 串聯與電壓／02 充放電原理／03 產氣與鼓包。
- 左側控制卡：「串聯數量」− 3S ＋；單芯電壓滑桿 3.2–4.2 V；三個快捷值（3.2 放電參考、3.7 標稱、4.2 滿電）；下方顯示總電壓（例 6S×4.04＝24.24 V；過充 4.34 V→26.04 V 變紅並示警）。
- 右側大圖：電芯並排、導線相連，下方顯示單芯電壓；充放電頁以粒子動畫表示鋰離子在正負極間移動；鼓包頁顯示軟包膨脹。

## 7. 無刷電機拆解實驗
- 左右兩張對照卡：A 有刷直流電機／B 外轉子無刷電機（12 槽 14 極）。
- 每卡：3D 剖面模型（可拖曳）、零件標註、底部「電刷換向示意」與「三相六步換相」按鈕（A+B−、A+C−、B+C−…目前步驟高亮）。
- 另有「電調工作原理」頁：01 有刷電調／02 無刷電調（電路板示意＋進度條）。

## 8. 無人機足球戰術實驗室（第一支影片前 1 分 40 秒）
- 頂部三模式分頁：「戰術編排」「自由試飛」「模擬對抗」，右上「遙控器設定」。
- 左欄：「場上球機 3 對 3」名單（藍隊 B1 進攻機、B2 輔攻機、B3 防守機；紅隊 R1–R3），「課堂預設」戰術按鈕（R3 換位／側翼突破／門前防守），說明框，「保存戰術／讀取戰術」。
- 中央 3D 場：綠色球場、紅藍兩色框架場邊、兩端直立圓環球門、球機以籠型球體表示並掛標籤；視角鈕（全景／俯視／側視／飛手視角／跟隨）；可顯示路線點（粉紅圓點）與指示。
- 右欄：即時數值（高度 m、速度 m/s）、航點高度滑桿、機頭朝向、「飛行路線 13 個航點」、航點下拉選擇與高度微調。
- 底部：「演示路線」綠鈕、「暫停／可准備」狀態、倍速。
- 模擬對抗：場中央倒數計時 02:50 與比分 0：0。

## 9. USB 控制設備接入
- 「遙控器設定」按鈕＋旁白「遙控器來實現虛擬飛行」；畫面未顯示協議細節。→ 本平台以瀏覽器 Gamepad API 實作（見 USB_CONTROLLER_COMPATIBILITY.md），未驗證任何特定廠牌協議。

## 10. 專項訓練、測驗與學習流程
- 流程：課程目錄 → 投影片講解 → 三維演示 → 考核標準 → 訓練技巧 → 虛擬實驗。
- 另有「流體實驗」（杯子裡真的空嗎？空氣流動、壓差阻力）、「無線電頻率」（2.4／5.8 GHz 波形對比）、AI 助手對話頁（「今天想學什麼？」）。
