# USB 遙控器相容性

## 做法
- 瀏覽器標準 **Gamepad API**（USB HID 遊戲控制器類）。不使用 WebUSB／Web Serial，不經任何廠商 SDK。
- **只控制網頁模擬器，不能也不會連到實體無人機。**
- 預設美國手（Mode 2）：軸 1 油門（反向）、軸 0 偏航、軸 3 俯仰（反向）、軸 2 橫滾；按鈕 0 緊急停止。
- 遙控器設定視窗：即時顯示各軸、換算後四個控制量；通道對應、反向、死區（0–0.3）、行程校準（最小／最大／中心）；設定存在該瀏覽器。
- 斷線提醒：`gamepaddisconnected` 後 15 秒內顯示紅色警告，並自動改回鍵盤／虛擬搖桿。
- 緊急停止：遙控器按鈕、空白鍵、畫面紅色按鈕；油門強制 −1、其他歸零。

## 測試結果
| 項目 | 結果 | 類型 |
|---|---|---|
| 辨識遙控器並以油門軸上升 | PASS | AUTOMATED（注入假 Gamepad） |
| 緊急停止鍵 | PASS | AUTOMATED（模擬） |
| 斷線提醒 | PASS | AUTOMATED（模擬） |
| 軸讀值：校準、反向、死區 | PASS | 單元測試 |
| 設定視窗 | PASS | AUTOMATED |
| **實體 USB 遙控器** | **未測試** | 沒有實體設備，**不能宣稱真實設備驗證完成** |

## 待實機確認
- 常見模擬器遙控器（例如以 USB HID 遊戲手把模式輸出的遙控器）在 Chrome／Edge 的軸編號與方向，可能和預設不同，需用設定視窗調整。
- Safari（iPad／iPhone）對 USB 遙控器支援有限，平板建議用虛擬搖桿。
- 瀏覽器要求「先按一個鍵或撥動搖桿」才會回報手把，屬瀏覽器隱私設計。
