# AI 檢測結果判讀

本文件提供 FDE-AI AI 助教回答「AI 檢測結果怎麼判斷」時的基本依據。AI 檢測只做初步提示，不能取代老師複核。

## 結果狀態

- PASS：照片或影片中主要檢查項目看起來正常，但仍需依課堂流程完成安全確認。
- WARNING：AI 找到可能有風險或信心度不足的項目，學生應重新拍攝清楚照片，並請老師確認。
- FAIL：AI 沒有偵測到必要零件，或結果顯示高風險狀態，不能進入通電、解鎖或實飛。

## F450 組裝照片判讀

判讀 F450 組裝照片時，應同時看：

1. 是否偵測到四顆馬達與四支機臂。
2. 是否偵測到 CW 正槳與 CCW 反槳。
3. 飛控箭頭、GPS / 指南針方向是否朝向機頭。
4. 電池是否固定在機身中心附近。
5. 線材是否鬆脫、壓到槳葉或接近馬達。

CW / CCW 只代表槳葉類型，不能單獨判斷是否裝對位置。仍要搭配機頭方向、馬達序號與馬達旋轉方向確認。

## 四面懸停影片判讀

判讀四面懸停影片時，應看：

1. 是否完成機頭朝前、朝右、朝後、朝左四個方向。
2. 懸停時是否明顯漂移。
3. 是否超出安全區域。
4. 起飛與降落是否平穩。
5. 影片是否清楚拍到完整動作。

## 學生看到結果後的下一步

- PASS：保存截圖與照片，交給老師做最後確認。
- WARNING：先不要通電或起飛，依提示重新檢查並補拍照片。
- FAIL：停止操作，回到組裝、接線或校正流程重新檢查。

任何涉及槳葉、馬達、電池、通電、解鎖或實飛的結果，都必須請老師或現場負責人確認。
