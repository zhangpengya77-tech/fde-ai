# 【10年内无人机入门必看】Ardupilot和DroneCAN多旋翼全网最好保姆级教程 p11 P9-遥控器和接收机和Radio校准 FAQ版

## Q1：本集适合放到 F450 RAG 知识库的哪个分类？

A1：建议分类为 `DroneCAN / 飞控 / 电调/马达 / 遥控器/接收机 / Mission Planner / 故障排除 / 装机`。如果后续人工复核发现主题更细，可再拆成飞控、CAN 设备、GPS、Mission Planner、故障排除等子类。

## Q2：为什么不能只保留摘要？

A2：无人机教学涉及接口、参数、线序、数值和操作顺序。摘要容易丢失关键数字和参数，所以必须保留完整逐字稿，再额外生成整理版、FAQ版和知识点版。

## Q3：逐字稿里的 DroneCAN 识别错误怎么办？

A3：Whisper 可能把 DroneCAN 识别成近音词。RAG 入库前应把明显错误标注为“需人工复核”，不要直接改成确定参数，除非已看过原视频画面或设备界面。

## Q4：哪些技术参数必须保留？

A4：必须保留 `SERIAL`、`UART`、`TX`、`RX`、`GPS`、`Compass`、`RNGFND`、`PWM`、`CAN`、`I2C`、`SPI`、`DroneCAN`、`ArduPilot`、`PX4`、`Mission Planner` 等关键词。

## Q5：如果学生照着视频操作失败，AI 教练应该怎么回答？

A5：先问清楚飞控型号、固件版本、接线方式、供电状态、地面站报错，再按“供电 -> 接线 -> 参数 -> 校准 -> 测试 -> 日志”的顺序排查。

## Q6：这类视频怎样用于 AI 老师？

A6：逐字稿用于完整检索，整理稿用于教学流程，FAQ用于问答，知识点版用于向量化切片，RAG完整文件用于保留上下文和引用来源。
