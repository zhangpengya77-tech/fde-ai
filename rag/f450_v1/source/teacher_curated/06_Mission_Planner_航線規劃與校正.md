# Mission Planner 航線規劃與校正

本文件提供 F450 使用 Pixhawk 2.4.8 搭配 Mission Planner 時的基礎流程。適用於 FDE-AI 1.0 的「作」與「測」階段。

## 連線前檢查

- 飛控 Pixhawk 2.4.8 已固定，箭頭朝機頭。
- USB 線或數傳連線穩定。
- 電池與電源模組接線正確。
- 第一次設定與馬達測試前，必須拆下所有槳葉。
- GPS / 指南針固定牢靠，方向正確，遠離強磁干擾。

## 基本設定順序

1. 選擇正確機架類型，F450 通常使用四軸 X 型。
2. 完成加速度計校正。
3. 完成指南針校正。
4. 完成遙控器校正。
5. 設定飛行模式。
6. 設定 FailSafe 失控保護。
7. 做無槳馬達測試，確認馬達序號與旋轉方向。
8. 確認所有警告處理後，才進入槳葉安裝與戶外測試。

## 航線任務基本概念

Mission Planner 航線任務通常包含：

- Takeoff：起飛點與起飛高度。
- Waypoint：航點，設定每個點的位置與高度。
- RTL：返航，任務結束或異常時回到返航點。

規劃航線時，應確認高度、路線、返航點與安全區域。新手不要直接在複雜場地執行自主航線，應先在模擬器或空曠安全場地由老師帶領測試。

## 常見錯誤

- 高度設定錯誤，導致航線過低或過高。
- 沒有確認返航點。
- GPS 訊號不足就嘗試執行任務。
- 指南針校正不良，造成航向異常。
- 槳葉未拆就做馬達測試，造成安全風險。

## AI 助教提醒

如果學生問「Mission Planner 怎麼設定」「無法解鎖」「航線怎麼規劃」，AI 助教應先提醒：檢查 Mission Planner 的警告訊息，完成校正，並在通電、馬達測試或實飛前請老師確認。
