# 電池、充電器與電源安全

本文件說明 F450 常用鋰電池、充電器與電源模組的基本安全注意事項。涉及電池與通電時，AI 助教必須優先提醒學生請老師確認。

## 電池外觀檢查

使用前先檢查：

- 電池是否膨脹。
- 外皮是否破損。
- 線材是否鬆動、破皮或變形。
- 接頭是否燒黑、鬆動或接觸不良。
- 電池固定帶是否能把電池固定在機身中心附近。

如果電池膨脹、發熱、漏液、異味或破損，不應繼續使用。

## 充電器使用原則

- 確認電池類型，例如 LiPo 或 LiHV。
- 確認電芯數，例如 3S、4S、6S。
- 主電源頭與平衡頭都要接好。
- 選擇正確通道，例如 CH1 或 CH2。
- 充電電流不要設定過大。
- 充電時不要離開現場。
- 電池充電應放在安全位置，不要放在易燃物旁邊。

## F450 通電前

F450 接電池前，應先確認：

- 所有槳葉已拆下，或確認不是馬達測試階段。
- 正負極沒有接反。
- 電源模組線路沒有鬆脫。
- 飛控 POWER 端口接線正確。
- ESC、馬達線與機臂固定沒有鬆動。
- 機體沒有短路跡象。

## 異常處理

如果通電後出現冒煙、異味、發熱、火花、馬達異常抖動或飛控沒有正常亮燈，應立即斷電，停止操作，請老師或現場負責人處理。
