# ArduPilot 和 DroneCAN 多旋翼保姆级教程 p01｜FAQ版

## Q1：这期视频主要讲什么？
A1：这期是 ArduPilot / APM 固件结合 DroneCAN 机载外设的多旋翼保姆级教程，使用 F450 作为入门平台，讲设备选购、充电器、物理装机、CAN 接线、ArduPilot 设置、DroneCAN 电调、地图和户外试飞。

## Q2：为什么教程选 F450？
A2：F450 便宜、好买、维修方便，适合初学者练习装机、接线、校准、调参和试飞。它是教学载体，不代表只能用于 F450。

## Q3：DroneCAN 相比 PWM / DShot 有什么优势？
A3：DroneCAN 可以让多个机载外设通过 CAN 总线接入飞控，减少线束复杂度，并可让 GNSS、罗盘、电调、电流计等设备被飞控统一识别和管理。

## Q4：CAN 总线接线最重要的原则是什么？
A4：保持线性拓扑，正确连接 CAN_H、CAN_L、GND 和供电，确认总线两端终端电阻，避免 CAN_H/CAN_L 接反或线束接触不良。

## Q5：DroneCAN 设备不在线怎么办？
A5：先检查供电，再检查 CAN_H/CAN_L 是否接反、终端电阻是否正确、线束是否松动、节点 ID 或波特率是否冲突，最后用 DroneCAN GUI Tool 或 Mission Planner 查看设备状态。

## Q6：F450 用 3S 还是 4S 电池？
A6：要看电机、电调、桨叶和飞控供电规格。视频中提到入门可用 3S 保守测试，也可根据动力需求使用 4S，但必须确认所有设备支持对应电压。

## Q7：选择 LiPo 电池时看哪些参数？
A7：至少看 S 数、电压、容量 mAh、C 数、最大放电电流、重量，以及是否满足电机和电调的需求。

## Q8：B6 或 D6 Pro 充电器设置时要注意什么？
A8：要设置正确的电池类型、S 数、充电电流，连接主充电线和平衡头。平衡头方向不能插反，黑线通常是负极侧。

## Q9：F450 底板焊点为什么要保护？
A9：F450 底板常作为分电板使用，裸露焊点或正负极短路可能导致电池损坏、起火或烧毁电调。

## Q10：电机转向反了怎么办？
A10：传统电调可交换任意两根三相线，DroneCAN 电调则可能通过参数修改转向。具体按电调类型和说明书操作。

## Q11：ArduPilot 设置中为什么要开启 CAN？
A11：如果使用 DroneCAN GNSS、罗盘、电调、电流计等外设，飞控必须启用 CAN 总线相关参数，才能发现和控制这些设备。

## Q12：Mission Planner 里要设置哪些核心内容？
A12：固件、机架类型、CAN 总线、GNSS、Compass、DroneCAN 电调、电流计、Initial Tune Parameter、加速度计校准、磁力计校准、遥控器校准和飞行模式。

## Q13：为什么不建议用太老的 ArduPilot 固件？
A13：过老固件可能缺少新的 DroneCAN 外设支持、参数项或安全修复，导致设备无法识别或功能不完整。

## Q14：DroneCAN 电调有什么需要特别检查的？
A14：要检查节点在线、输出顺序、电机转向、参数与 ArduPilot 电机编号一致，并验证紧急停转和未起转保护。

## Q15：MP 地图为什么要提前设置？
A15：户外测试时网络可能不稳定，提前修改地图引擎和下载地图数据，能避免现场无法加载地图。

## Q16：新手可以夜晚试飞吗？
A16：不建议。夜晚可视条件差，风险更高。新手应在白天、开阔、合规场地低空近距离试飞。
