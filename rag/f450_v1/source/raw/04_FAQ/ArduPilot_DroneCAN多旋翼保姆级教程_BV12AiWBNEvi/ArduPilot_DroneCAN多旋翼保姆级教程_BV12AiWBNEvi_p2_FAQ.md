# DroneCAN RGB航行灯 FAQ版

## Q1：为什么 F450 或多旋翼要加 DroneCAN RGB 航行灯？

A1：主要用于增强飞控状态显示和夜间方向识别。高亮 RGB 航行灯可以安装在机臂外侧，通过左红、右绿、尾白等方式帮助操作者判断机头方向、左右方向和机尾位置。

## Q2：DroneCAN RGB 航行灯是直接接 PWM 口吗？

A2：不是。该视频讲的是通过 CAN 总线接入的 DroneCAN RGB 航行灯，不是普通 PWM 灯。它需要接入飞控 CAN 总线，并通过 DroneCAN 节点参数进行配置。

## Q3：RGB 航行灯可以由 ArduPilot 或 PX4 自动控制吗？

A3：可以。灯具可接收飞控通过 DroneCAN 下发的灯光控制命令。具体支持程度与飞控固件版本、灯具固件和参数设置有关，需人工验证。

## Q4：什么是 `Light ID`？

A4：`Light ID` 是飞控通过 DroneCAN 命令发送给航行灯的灯光编号。RGB 灯具只有在自己的 `LEDID` 与飞控命令中的 `Light ID` 匹配时，才会响应该命令。

## Q5：什么是 `LEDID`？

A5：`LEDID` 是 RGB 灯具本身的编号参数，用来决定该灯响应哪个 `Light ID`。例如灯具 `LEDID = 0` 时，通常会响应 `Light ID = 0` 的飞控灯光命令。

## Q6：为什么设置了 RGB 灯，但是不跟飞控状态变化？

A6：常见原因包括：灯具没有接入 CAN 总线、供电异常、CAN_H/CAN_L 接反、终端电阻错误、节点没有上线、灯具 `LEDID` 与飞控下发的 `Light ID` 不一致，或者飞控固件没有发送对应灯光命令。

## Q7：新增多个 RGB 灯后，为什么要检查终端电阻？

A7：CAN 总线通常只需要总线两端各一个 120Ω 终端电阻。如果飞控和 GNSS 已经各自带终端电阻，再给每个 RGB 灯都保留终端电阻，可能导致总线阻抗异常，节点通信不稳定。

## Q8：视频里为什么要把 ESC 的 CAN 线往内挪一格？

A8：目的是腾出 CAN1 接口位置给新增 RGB 灯使用。实际接法要以飞控载板、接口定义和当前 CAN 总线结构为准，不能只按视频盲插。

## Q9：RGB 灯常亮模式怎么设置？

A9：进入灯具参数页面，将灯光模式设置为常亮，再设置红、绿、蓝三通道数值。常见训练方案是左红、右绿、尾白。

## Q10：RGB 灯闪烁模式怎么设置？

A10：进入灯具参数页面，将模式设置为闪烁，再设置亮灯时间、灭灯时间等参数。不同灯具固件的参数名可能不同，应按实际界面人工复核。

## Q11：`LED Offset MS` 有什么用？

A11：`LED Offset MS` 用于设置灯具闪烁的时间偏移，单位通常是毫秒。多个灯如果设置不同偏移量，就可以形成交替闪烁效果。

## Q12：呼吸灯模式适合飞行吗？

A12：呼吸灯适合展示、状态提示或教学演示。若用于夜间方向识别，通常常亮或规则闪烁更直观。视频提到 `LED Type = 3` 可设置呼吸灯，但参数值需人工验证。

## Q13：左红、右绿、尾白是不是固定标准？

A13：视频中使用左红、右绿、尾白作为方向识别方案，也符合常见航行灯识别习惯。但实际课程、法规和机型标准仍需按当地规范人工确认。

## Q14：节点上线但灯不亮，应该先查什么？

A14：先查模式参数是否为关闭、亮度值是否为 0、RGB 三通道是否设置正确、`LEDID` 是否匹配飞控命令、供电电压是否稳定，再检查灯具固件是否需要重启后生效。

## Q15：这类内容适合放进 RAG 知识库吗？

A15：适合。它能形成 CAN 总线外设安装、RGB 灯参数设置、飞控状态灯控制、夜间方向识别和故障排查等知识点，适合 AI 教练回答装机和调试问题。
