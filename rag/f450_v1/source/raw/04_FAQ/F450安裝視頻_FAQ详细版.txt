F450安装视频 FAQ详细版
====================

说明:
本 FAQ 从 Whisper 原始逐字稿派生。
原始逐字稿不覆盖、不删改。
答案中保留视频里的数字、接口名、部件名和参数词。


Q1: 这个视频主要讲什么？
A1: 视频主要讲 F450 四轴无人机硬件组装，包括 ESC 和电源线焊接、电机安装、电源模块安装、机臂安装、飞控安装、GPS 安装、LED 安装、接收机安装、线束整理和 M1/M2/M3/M4 电机接口连接。


Q2: F450 组装第一步是什么？
A2: 第一步是焊接 ESC 和电源线。视频中需要分电板、4 个 ESC 调速器、1 个 XT60 公头电源线。先给焊盘预上锡，再焊接 ESC 正负极和电源线正负极。


Q3: ESC 电源线怎么焊？
A3: ESC 电源线分正极和负极。黑色负极线焊在负极焊点上，红色正极线焊在正极焊点上。焊接时用镊子夹住电源线，避免烫伤。线头和焊点叠在一起，用电烙铁加热到焊锡融化并包住线头。


Q4: 焊接 ESC 时最重要的注意事项是什么？
A4: 不能焊错正负极。负极焊负极，正极焊正极。焊接完成后建议检查是否虚焊、短路、焊点松动。


Q5: F450 有几个电机？
A5: F450 是四轴无人机，有四个机臂和四个电机。视频中每个电机用四颗螺丝固定。


Q6: 安装电机时为什么要注意螺丝长度？
A6: 视频明确提醒螺丝长度不要顶到电机铜线圈。如果螺丝顶到线圈，电机可能直接损坏。


Q7: 电机线应该朝哪个方向？
A7: 视频中电机线朝机臂方向，安装后将电机线绕到机臂底下，方便后续与 ESC 连接和整理线束。


Q8: 电源模块怎么安装？
A8: 视频中将 3M 胶粘在电源模块背面，然后把电源模块粘在分电板前端或后端。随后将电源模块正极线和 ESC 正极连接，负极线和 ESC 负极连接。


Q9: F450 机头方向怎么判断？
A9: 视频中红色机臂为机头方向。安装机臂时要看好位置，飞控和 GPS 的箭头也要指向红色机臂方向。


Q10: 电机线和 ESC 三相线有没有固定顺序？
A10: 视频中说明初装时没有固定顺序，可以随意插，后期调节参数时可以再更改。知识库补充: 后续必须通过电机测试确认电机方向，方向不对时通常交换任意两根电机线。


Q11: ESC 怎么固定？
A11: 电机线和 ESC 插好后，把线绕到合适长度，用扎带穿过机臂固定 ESC。其余 ESC 用相同方法固定，最后剪掉多余扎带。


Q12: 飞控为什么要装在中心？
A12: 视频中说明飞控是无人机的大脑，必须安装在无人机中心位置。安装时用直尺测量上盖板中心和飞控中心，用十字线对齐后用 3M 胶固定。


Q13: 飞控箭头应该朝哪里？
A13: 飞控上的小箭头应指向机头方向。视频中机头是红色机臂方向，所以飞控箭头朝红色机臂安装。


Q14: GPS 怎么安装？
A14: 视频中 GPS 和飞控一样有小箭头，箭头都指向机头方向。视频将 GPS 安装在无人机左上角位置，并在固定后整理线束。


Q15: LED 灯装在哪里？
A15: 视频中 LED 安装在机尾方向，也就是白色机臂之间，方便观察无人机实时状态。LED 用扎带穿过机臂固定。


Q16: 接收机怎么安装？
A16: 视频中接收机找到 S8R 端口，将配套排线插入底部端口，注意卡槽不要插反。接收机可用 3M 胶或扎带固定在上盖板上。


Q17: 接收机线接到哪里？
A17: 视频中接收机 S8R 线接到飞控 X2 端口。注意具体飞控型号不同，接口命名可能不同，实际接线应以飞控说明为准。


Q18: 电源模块线接到哪里？
A18: 视频中电源模块线绕到机身内部后连接到 X3 端口。


Q19: GPS 线接到哪里？
A19: 视频中 GPS 线连接飞控 EXP 端口。


Q20: LED 线接到哪里？
A20: 视频中 LED 线连接飞控 DOU LED 端口。


Q21: 电机输出怎么接？
A21: 视频中四个机臂分别对应 1 号、2 号、3 号、4 号电机。1 号电机连接飞控 M1 端口，2 号电机连接 M2 端口，其余电机按编号依次连接。


Q22: 这个视频完成后能直接飞吗？
A22: 不能。视频完成的是硬件组装。后续还需要刷固件、校准传感器、校准遥控器、设置飞行模式、检查电机编号和转向、设置 failsafe、完成首飞前检查。


Q23: 这个视频适合归入哪个知识库分类？
A23: 适合归入 01_F450机架、02_电机电调电源、03_Pixhawk飞控硬件，以及 07_常见故障检修 中的首飞前装配检查相关内容。

# 三、知识点（Knowledge）

## 概念

F450/Pixhawk 是开源无人机装调训练常用组合，常见知识点包括飞控接线、GPS、Compass、遥控器、电调、马达、Mission Planner、ArduPilot/PX4 参数和飞行安全检查。

## 参数

参数名：GPS / Compass / SERIAL / UART / PWM / CAN / I2C / SPI / RNGFND
中文意思：定位、罗盘、串口、通信接口、PWM输出、CAN总线、I2C总线、SPI总线、测距参数
建议值：按飞控固件版本、硬件连接、Mission Planner 实际提示和视频原文确认，不能脱离设备直接套用。

## 常见故障

故障：无法解锁、GPS漂移、罗盘校准失败、起飞自旋、马达方向错误、遥控器校准异常、地面站无法连接。
原因：GPS搜星不足、HDOP过高、罗盘未校准、飞控方向错误、电调/马达/桨叶方向错误、安全开关或飞行模式未满足、驱动或端口错误。
解决方法：按原文、Mission Planner 报错、飞控状态灯、GPS/Compass状态、遥控器校准、电调马达方向逐项检查。

# 四、FAQ

Q1：
GPS模式无法解锁怎么办？

A1：
先检查GPS搜星数量是否超过10颗、罗盘是否校准、HDOP是否小于2、安全开关状态、飞行模式设置和飞控报错信息。

Q2：
F450 起飞自旋或姿态不稳怎么办？

A2：
优先检查马达顺序、马达转向、桨叶正反、飞控安装方向、机架类型、罗盘方向、电调校准和遥控器通道正反向。
