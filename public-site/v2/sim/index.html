🔗 連線方式

五種操作方式

進入任一訓練後按畫面上的「🔗 連線方式」切換。優先順序：實體遙控器 → 手機 → 手勢 → 原子筆 → 鍵盤；訊號中斷超過 0.25 秒自動懸停。

  • ⌨️ 鍵盤：W/S 前後、A/D 左右、Q/E 轉向、R/F 升降。
  • 🎮 實體遙控器：USB 線接電腦（模擬器模式），撥一下搖桿自動接手。
  • ✋ 手勢（新）：對鏡頭伸手，手掌移動＝搖桿、握拳＝懸停；第一次會下載約 17MB 辨識模型。
  • 🖊️ 原子筆＋鏡頭（新）：點一下有顏色的筆蓋，筆移動＝搖桿；左手再一支不同顏色的筆＝完整四軸。
  • 📱 手機遙控器（新）：掃 QR 碼配對、雙拇指或體感操作；需教學主機開機，手機與電腦連同一個 Wi‑Fi。

鏡頭影像只在你的瀏覽器計算，不錄影、不上傳。這裡是公開網站，練飛成績不會保存；想把成績存入成長日誌，請到教學網站登入學員帳號後練習。

遙控器準備：連接 USB-C 資料線 → 遙控器選擇 USB Joystick (HID) → 輕推搖桿供瀏覽器辨識 → 油門歸零後開始。行動裝置可閱讀與操作鍵盤替代介面，但不作 USB HID 遙控器相容性承諾。
